# Миграция: Добавление функциональности проектов

## Обзор изменений

В версии с поддержкой проектов добавлена возможность группировать интеграции для лучшей организации.

## Что нового

1. **Новая модель данных**: Таблица `projects` для хранения проектов
2. **Связь с интеграциями**: Поле `project_id` в таблице `integrations`
3. **Новые страницы UI**: Управление проектами через веб-интерфейс
4. **API endpoints**: Новые маршруты для работы с проектами

## Миграция базы данных

### Автоматическая миграция (рекомендуется)

Просто перезапустите сервер - GORM автоматически создаст новые таблицы и поля:

```bash
go run cmd/server/main.go
```

### Ручная миграция

Если вы предпочитаете ручную миграцию:

**Для MySQL:**
```bash
mysql -u username -p database_name < migrations/002_add_projects.sql
```

**Для SQLite:**
```bash
sqlite3 dmIntegroff.db < migrations/002_add_projects_sqlite.sql
```

## Обратная совместимость

✅ **Полная обратная совместимость**

- Все существующие интеграции продолжат работать
- Поле `project_id` опциональное (может быть NULL)
- Интеграции без проекта отображаются как "Без проекта"
- Никаких изменений в API вебхуков

## Что происходит с существующими данными

1. **Интеграции**: Все существующие интеграции получат `project_id = NULL`
2. **Функциональность**: Все интеграции продолжат работать как раньше
3. **UI**: В списке интеграций появится колонка "Проект" со значением "Без проекта"

## Новые возможности

После миграции вы сможете:

1. Создавать проекты через `/projects/create`
2. Добавлять интеграции в проекты
3. Просматривать все интеграции проекта
4. Создавать новые интеграции сразу с привязкой к проекту

## Проверка миграции

После запуска сервера проверьте:

1. **Логи сервера**: Должно быть сообщение "Database migration completed"
2. **Веб-интерфейс**: Появится пункт меню "📁 Проекты"
3. **База данных**: 
   ```sql
   -- Проверка таблицы projects
   SELECT * FROM projects;
   
   -- Проверка поля project_id в integrations
   DESCRIBE integrations;
   ```

## Откат изменений

Если нужно откатить изменения:

**Для MySQL:**
```sql
ALTER TABLE integrations DROP FOREIGN KEY integrations_ibfk_2;
ALTER TABLE integrations DROP COLUMN project_id;
DROP TABLE projects;
```

**Для SQLite:**

## Поддержка

Если возникли проблемы:

1. Проверьте логи сервера: `dmIntegroff.log`
2. Убедитесь, что используете последнюю версию Go (1.20+)
3. Проверьте права доступа к базе данных
4. Создайте issue на GitHub с описанием проблемы
