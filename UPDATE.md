# 🔄 Обновление dmIntegroff

## Быстрое обновление

После `git pull` выполните:

```bash
# 1. Применить миграции БД
.\dmIntegroff-admin.exe --migrate

# 2. Пересобрать приложение
go build -o dmIntegroff.exe cmd/server/main.go

# 3. Перезапустить (Ctrl+C в старом терминале, затем)
.\dmIntegroff.exe
```

## Что делает миграция

CLI использует GORM AutoMigrate, который:
- ✅ Автоматически создает новые таблицы
- ✅ Добавляет новые колонки в существующие таблицы
- ✅ Сохраняет все существующие данные
- ✅ НЕ удаляет старые колонки (для безопасности)

## Проверка обновления

### Тест логирования:
```powershell
.\test_logs.ps1
```
Откройте http://localhost:8080/logs - должны отображаться заголовки

### Тест проектов:
```bash
.\test_projects.sh
```
Откройте http://localhost:8080/projects - должны отображаться проекты

## Откат (если что-то пошло не так)

```bash

copy dmintegroff.db.backup dmintegroff.db

# 2. Откатить код
git checkout <previous-commit>

# 3. Пересобрать
go build -o dmIntegroff.exe cmd/server/main.go
```
