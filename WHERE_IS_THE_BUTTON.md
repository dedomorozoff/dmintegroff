# 📍 Где находится кнопка "Использовать как образец данных"

## Расположение кнопки

Кнопка находится **внутри раскрытых деталей каждого запроса** на странице тестового webhook.

## Как увидеть кнопку

### Шаг 1: Создайте тестовый webhook
1. Перейдите на дашборд: `http://localhost:8080/dashboard`
2. Нажмите кнопку **"Создать тестовый вебхук"**
3. Вы попадете на страницу вида: `http://localhost:8080/webhook-test/TOKEN`

### Шаг 2: Отправьте тестовый запрос

**Вариант A: Используйте кнопку в интерфейсе**
- На странице webhook нажмите **"Отправить тестовый запрос"**
- Это отправит тестовый JSON на ваш webhook

**Вариант B: Используйте curl**
```bash
curl -X POST "http://localhost:8080/webhook/test/ВАШ_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"test": "data", "user": {"id": 123}}'
```

### Шаг 3: Раскройте детали запроса

После отправки запроса вы увидите список запросов:

```
┌─────────────────────────────────────────────┐
│ POST  /                          15:30:45   │  ← Нажмите сюда
│                                      ▼      │
└─────────────────────────────────────────────┘
```

**Нажмите на запрос** (или на стрелку ▼), чтобы раскрыть детали.

### Шаг 4: Увидите кнопку

После раскрытия деталей вы увидите:


## Что происходит при нажатии

1. **Открывается модальное окно** со списком ваших интеграций
2. **Выбираете интеграцию** из списка
3. **Автоматически сохраняется** body запроса в SamplePayload интеграции
4. **Перенаправляет** на страницу настройки маппинга
5. **Образец данных уже заполнен** и готов к использованию

## Важно!

- ✅ Кнопка появляется **в каждом запросе** (как в существующих, так и в новых)
- ✅ Нужно **раскрыть детали** запроса, чтобы увидеть кнопку
- ✅ Кнопка находится **внизу деталей**, после информации о запросе
- ✅ Работает для **всех запросов**, даже если body пустой

## Быстрый тест

```bash
# 1. Запустите приложение
./dmintegroff.exe

# 2. Откройте браузер
http://localhost:8080/login

# 3. Создайте тестовый webhook на дашборде

# 4. Отправьте запрос (замените TOKEN)
curl -X POST "http://localhost:8080/webhook/test/TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"test": true}'

# 5. На странице webhook:
#    - Нажмите на запрос (раскрыть)
#    - Прокрутите вниз
#    - Увидите кнопку "Использовать как образец данных"
```

## Если не видите кнопку

### Проверьте:
1. ✅ Запрос раскрыт (нажали на него)?
2. ✅ Прокрутили вниз до конца деталей?
3. ✅ Есть хотя бы один запрос в списке?
4. ✅ Приложение перезапущено после изменений?

### Проверка в коде:
```bash
# Проверьте, что изменения применены
grep -n "Использовать как образец данных" templates/pages/webhook_test.html
```

Должно показать строку с кнопкой.
