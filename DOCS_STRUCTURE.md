## Структура проекта

```

├── UPDATE.md              # Обновление

├── PRODUCTION.md          # Деплой

├── FEATURES.md            # Список возможностей
├── LICENSE                # Лицензия MIT
│
├── docs/                  # Дополнительная документация
│   ├── PROJECTS.md        # Работа с проектами
│   ├── TECHNICAL_DOCS.md  # Техническая документация
│   ├── PROGRAMMER_GUIDE.md # Руководство программиста
│   └── EXAMPLES.md        # Примеры

├── tests/                 # Тестовые скрипты
│   └── test_logs.ps1      # Тест логирования
│
├── cmd/                   # Исходный код приложений
├── internal/              # Внутренние пакеты
├── static/                # Статические файлы
└── templates/             # HTML шаблоны
```

## Принципы организации

1. **Корень проекта** - основная документация для быстрого доступа
2. **docs/** - подробная техническая документация
3. **Краткость** - каждый документ решает одну задачу
4. **Актуальность** - документация обновляется вместе с кодом
5. **Ссылки** - документы связаны между собой для удобной навигации
