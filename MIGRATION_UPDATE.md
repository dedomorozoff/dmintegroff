# Обновление структуры миграций

**Дата:** 09.12.2024  
**Статус:** ✅ Завершено

## Краткое описание

Все SQL миграции (34 файла) были объединены в 2 консолидированных файла схемы для упрощения развертывания и поддержки.

## Изменения

### Было
- 34+ отдельных файла миграций
- Сложно отследить полную структуру БД
- Риск пропустить миграцию при ручной установке

### Стало
- 2 файла: `schema_sqlite.sql` и `schema_mysql.sql`
- Полная схема БД в одном месте
- Простое развертывание новых инстансов
- Старые файлы сохранены в `migrations/legacy/` для истории

## Файлы

### Новые файлы
```
migrations/
├── schema_sqlite.sql              # Консолидированная схема SQLite
├── schema_mysql.sql               # Консолидированная схема MySQL
├── README.md                      # Обновленная документация
├── QUICK_START.md                 # Быстрый старт
├── MIGRATION_CONSOLIDATION.md     # Детальное описание изменений
└── legacy/                        # Архив старых миграций
    ├── README.md
    └── [34 старых файла миграций]
```

## Обратная совместимость

✅ **Полная обратная совместимость**

- Код не изменился - используется GORM AutoMigrate
- Существующие базы данных продолжат работать
- Старые миграции сохранены для истории

## Обновленные файлы кода

- `cmd/admin/main.go` - Добавлены модели WebhookTest и WebhookTestRequest в миграцию

## Как использовать

### Для разработчиков
```bash
# Просто запустите приложение
go run cmd/server/main.go

# Или используйте admin CLI
go run cmd/admin/main.go
```

### Для новых установок
```bash
# SQLite
sqlite3 dmintegroff.db < migrations/schema_sqlite.sql

# MySQL
mysql -u username -p database_name < migrations/schema_mysql.sql
```

## Включенные таблицы

Консолидированная схема включает все 7 таблиц:

1. **users** - Пользователи с демо-режимом
2. **projects** - Проекты
3. **integrations** - Интеграции (OAuth, GraphQL, enrichment, webhooks)
4. **integration_outputs** - Множественные выходы
5. **request_logs** - Логи запросов/ответов
6. **webhook_tests** - Тестовые вебхуки
7. **webhook_test_requests** - Захваченные тестовые запросы
