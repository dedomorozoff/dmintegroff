### dmIntegroff v1.6.0 - AI Revolution

Рады представить революционное обновление **dmIntegroff** — первую в мире систему интеграций с встроенным AI-ассистентом!

dmIntegroff позволяет создавать интеграции между любыми API за минуты вместо часов благодаря искусственному интеллекту. Просто опишите задачу на естественном языке — AI создаст готовую интеграцию автоматически.

## Основные возможности

✅ **AI-Ассистент** - автоматическое создание интеграций по описанию задачи  
✅ **Умный анализ данных** - AI определяет структуру и предлагает оптимальный маппинг  
✅ **База знаний API** - встроенная поддержка Slack, Telegram, популярных CRM  
✅ **Множественные выходы** - один webhook может отправлять данные на несколько Target API  
✅ **Мультиформатность** - поддержка JSON, XML, form-data, plain text  
✅ **История запросов** - детальное логирование с поиском и фильтрацией  
✅ **Валидация конфигурации** - тестирование подключений перед активацией  
✅ **Готовые шаблоны** - библиотека настроек для популярных сервисов  
✅ **OAuth 2.0 / GraphQL** - полная поддержка современных API стандартов  
✅ **Экспорт данных** - CSV/JSON экспорт для аналитики и аудита

## Установка

Скачайте бинарник для вашей платформы из раздела Releases, распакуйте и запустите. Подробная инструкция в README.md

Для использования AI-ассистента добавьте OpenAI API ключ в файл `.env`:
```
OPENAI_API_KEY=your_api_key_here
```

## Миграция

База данных обновится автоматически при первом запуске. Все существующие интеграции сохранятся и продолжат работать. Рекомендуется создать резервную копию перед обновлением.
