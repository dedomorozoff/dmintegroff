# Установка демо-режима

## Что было добавлено

1. **Модель User** - добавлены поля `is_demo` и `expires_at`
2. **Контроллер авторизации** - поддержка GET-параметров для автоматической регистрации
3. **Сервис интеграций** - проверка ограничений для демо-пользователей
4. **Шаблон логина** - автозаполнение полей и уведомление о регистрации
5. **Миграции** - SQL-скрипты для обновления БД
6. **Документация** - руководства по использованию

## Применение изменений

### Шаг 1: Обновите базу данных

Выберите один из способов:

**Способ 1: Автоматическая миграция (рекомендуется)**
```bash
go run cmd/admin/main.go
# Выберите "1. Выполнить миграцию базы данных"
```

**Способ 2: Через скрипт**
```bash
go run scripts/apply_demo_mode_migration.go
```

**Способ 3: Вручную**
```bash
# SQLite
sqlite3 dmintegroff.db < migrations/006_add_demo_users_sqlite.sql

# MySQL
mysql -u username -p database_name < migrations/006_add_demo_users.sql
```

### Шаг 2: Настройте .env

Добавьте в файл `.env`:

```env
# Демо-режим
DEMO_MODE=true
DEMO_SECRET=your-secret-key-here
DEMO_TARGET_URL=https://webhook.site/your-webhook-id
```

Замените:
- `your-secret-key-here` - на свой секретный ключ
- `your-webhook-id` - на ID вашего webhook.site или другого тестового сервиса

### Шаг 3: Перезапустите приложение

```bash
# Остановите текущий процесс (Ctrl+C)
# Запустите заново
go run cmd/server/main.go
```

### Шаг 4: Протестируйте

Откройте в браузере:
```
http://localhost:8080/login?demo_key=your-secret-key-here&username=demo&password=demo123
```

## Проверка работы

1. ✅ Страница логина показывает сообщение о регистрации
2. ✅ Поля логина и пароля заполнены автоматически
3. ✅ Можно войти в систему
4. ✅ Создание интеграций работает
5. ✅ Вебхуки отправляются только на DEMO_TARGET_URL
6. ✅ Демо-пользователи удаляются через 24 часа

## Отключение демо-режима

Установите в `.env`:
```env
DEMO_MODE=false
```

## Безопасность

⚠️ **Важно:**
- Используйте сложный `DEMO_SECRET`
- Не включайте `DEMO_MODE=true` в продакшене
- Демо-пользователи имеют ограниченные права (роль specialist)
- Вебхуки ограничены только разрешенным URL
