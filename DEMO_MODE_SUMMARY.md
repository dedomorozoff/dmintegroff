## 🎯 Основные возможности

### 1. Автоматическая регистрация
```
GET /login?demo_key=SECRET&username=demo&password=pass
```
- Проверка секретного ключа
- Создание временного пользователя
- Автозаполнение формы логина

### 2. Ограничения безопасности
- Роль: только `specialist`
- Вебхуки: только на `DEMO_TARGET_URL`
- Срок действия: 24 часа

### 3. Автоматическая очистка
- При заходе на страницу логина
- Удаление истекших пользователей
- Индекс для быстрой очистки

## ⚙️ Конфигурация

Добавьте в `.env`:
```env
DEMO_MODE=true
DEMO_SECRET=your-secret-key
DEMO_TARGET_URL=https://webhook.site/your-id
```
