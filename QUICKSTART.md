# 🚀 Быстрый старт dmIntegroff

Пошаговое руководство для запуска dmIntegroff за 5 минут.

## 📋 Требования

- **Go 1.25+** - [Скачать](https://golang.org/dl/)
- **Git** - для клонирования репозитория

## ⚡ Установка за 3 шага

### 1. Клонирование и настройка

```bash
# Клонируйте репозиторий
git clone https://github.com/dedomorozoff/dmintegroff.git
cd dmIntegroff

# Установите зависимости
go mod tidy

# Скопируйте конфигурацию
cp .env.example .env
```

### 2. Запуск сервера

```bash
# Запустите сервер
go run cmd/server/main.go
```

Вы увидите:
```
INFO[2024-12-28T10:00:00Z] Starting dmIntegroff server on :8080
INFO[2024-12-28T10:00:00Z] Database connected successfully
INFO[2024-12-28T10:00:00Z] Server is ready to handle requests
```

### 3. Первый вход

Откройте браузер: **http://localhost:8080**

**Учетные данные по умолчанию:**
- Логин: `admin`
- Пароль: `admin`

⚠️ **Важно:** Смените пароль после первого входа в разделе "Настройки"!

## 🎯 Создание первой интеграции

### Шаг 1: Создайте интеграцию

1. Перейдите в **"Интеграции"** → **"Создать"**
2. Заполните форму:
   - **Название:** "Тест Slack"
   - **Target API URL:** `https://hooks.slack.com/services/YOUR/SLACK/WEBHOOK`
   - **HTTP метод:** POST
3. Нажмите **"Создать"**

### Шаг 2: Получите webhook URL

После создания вы получите уникальный webhook URL:
```
http://localhost:8080/webhook/abc123def456
```

### Шаг 3: Отправьте тестовые данные

```bash
curl -X POST http://localhost:8080/webhook/abc123def456 \
  -H "Content-Type: application/json" \
  -d '{
    "order_id": "12345",
    "customer": "Иван Иванов",
    "amount": 1500,
    "status": "paid"
  }'
```

### Шаг 4: Настройте маппинг

1. Вернитесь в интерфейс dmIntegroff
2. Перейдите к созданной интеграции → **"Настроить"**
3. Система автоматически захватила структуру данных
4. Настройте маппинг для Slack:

**Простой маппинг:**
```
order_id → text
customer → username
amount → channel
```

**Или кастомный JSON шаблон:**
```json
{
  "text": "Новый заказ #{{order_id}} от {{customer}} на сумму {{amount}} руб.",
  "channel": "#orders",
  "username": "dmIntegroff Bot"
}
```

### Шаг 5: Активируйте интеграцию

1. Нажмите **"Сохранить маппинг"**
2. Нажмите **"Активировать интеграцию"**
3. Готово! 🎉

## 🧪 Тестирование

### Встроенный тестовый webhook

1. Перейдите в **"Инструменты"** → **"Тестовый webhook"**
2. Получите временный URL для тестирования
3. Отправляйте запросы и смотрите результаты в реальном времени

### Отправка тестового запроса

```bash
curl -X POST http://localhost:8080/webhook/abc123def456 \
  -H "Content-Type: application/json" \
  -d '{
    "order_id": "67890",
    "customer": "Мария Петрова",
    "amount": 2500,
    "status": "paid"
  }'
```

## 🔧 Настройка

### Основные параметры в .env

```env
# Порт сервера
PORT=8080

# База данных (SQLite по умолчанию)
DB_TYPE=sqlite
DB_DSN=dmintegroff.db

# Секретный ключ сессий (ОБЯЗАТЕЛЬНО смените!)
SESSION_SECRET=your-super-secret-key-change-this-in-production

# Уровень логирования
LOG_LEVEL=info
LOG_FILE=dmintegroff.log
```

### Смена пароля администратора

**Через интерфейс:**
1. Войдите как admin
2. Перейдите в **"Настройки"**
3. Смените пароль

**Через CLI:**
```bash
go run cmd/admin/main.go reset-password admin
```

## 🆘 Решение проблем

### Сервер не запускается

```bash
# Проверьте версию Go
go version

# Проверьте зависимости
go mod tidy

# Проверьте порт
netstat -an | grep :8080
```

### Ошибки подключения к базе данных

```bash
# Проверьте права доступа к файлу БД
ls -la dmintegroff.db

# Пересоздайте БД
rm dmintegroff.db
go run cmd/server/main.go
```

### Проблемы с webhook

1. Проверьте URL в логах
2. Убедитесь что интеграция активна
3. Проверьте формат JSON данных
