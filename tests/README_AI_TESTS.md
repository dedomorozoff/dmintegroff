# Тесты AI для создания интеграций

Этот набор тестов проверяет работу AI системы для автоматического создания webhook интеграций в dmIntegroff.

Проверяет базовую функциональность создания интеграций с помощью AI:
- ✅ Создание интеграций для популярных сервисов (Slack, Telegram, Discord, Salesforce)
- ✅ Обработка различных типов входных данных
- ✅ Генерация корректных маппингов и шаблонов
- ✅ Валидация результатов создания
- ✅ Тестирование популярных API и быстрых предложений

**Ключевые тест-кейсы:**
- Slack уведомления с данными заказов
- Telegram бот для лидов
- Discord webhook для системных событий
- CRM интеграция с Salesforce
- Email уведомления
- Пользовательские webhook'и

## Конфигурация AI для тестов

Тесты работают в двух режимах:

### 1. Без реального AI (по умолчанию)
```go
config := &ai.AIConfig{
    Enabled: false, // Отключаем реальный AI
}
```
- Использует локальную генерацию маппингов
- Быстрое выполнение
- Не требует API ключей
- Подходит для CI/CD

### 2. С реальным AI (опционально)
```go
config := &ai.AIConfig{
    Enabled: true,
    OpenRouterAPIKey: "your-api-key",
    OpenRouterModel: "anthropic/claude-3.5-sonnet",
}
```
- Использует реальный AI для генерации
- Более точные результаты
- Требует API ключ
- Медленнее выполнение

## Отладка тестов

### Если тесты не проходят:

1. **Проверьте зависимости:**
   ```bash
   go mod tidy
   ```

2. **Проверьте базу данных:**
   - Убедитесь, что БД инициализирована
   - Проверьте подключение к БД

3. **Проверьте логи:**
   - Тесты выводят подробную информацию
   - Ищите ошибки в JSON парсинге
   - Проверьте валидацию полей

4. **Запустите отдельные тесты:**
   ```bash
   go test -v ./tests -run TestAIIntegrationPrompts/Slack -timeout 30s
   ```

### Частые проблемы:

**Ошибка JSON парсинга:**
- Проверьте корректность тестовых данных
- Убедитесь, что шаблоны генерируются в правильном формате

**Timeout ошибки:**
- Увеличьте timeout для медленных систем
- Проверьте производительность AI генератора

**Ошибки валидации:**
- Проверьте ожидаемые поля в assertions
- Убедитесь, что API URLs генерируются корректно

## Расширение тестов

### Добавление новых сценариев:

1. **Добавьте тест-кейс в соответствующий файл:**
   ```go
   {
       name: "Новый сценарий",
       description: "Описание интеграции",
       sampleData: `{"field": "value"}`,
       expectedType: "api_type",
       shouldWork: true,
   }
   ```

2. **Добавьте валидацию результата:**
   ```go
   validation: func(t *testing.T, result *ai.CreatedIntegration) {
       assert.Contains(t, result.TargetURL, "expected_service")
       // дополнительные проверки
   }
   ```

3. **Запустите новый тест:**
   ```bash
   go test -v ./tests -run "TestName/Новый сценарий"
   ```

### Добавление новых API:

1. **Обновите `ai/suggestions.go`:**
   - Добавьте новый API в `GetPopularAPIs()`
   - Добавьте шаблоны для API

2. **Обновите `ai/generator.go`:**
   - Добавьте генерацию шаблонов для нового API
   - Обновите логику определения API

3. **Добавьте тесты:**
   - Создайте тест-кейсы для нового API
   - Проверьте корректность генерации
