# Тест каскадного удаления интеграций

## Цель
Проверить, что при удалении проекта автоматически удаляются все его интеграции.

## Предварительные условия
1. База данных с примененной миграцией 004
2. Запущенное приложение
3. Авторизованный пользователь

## Шаги тестирования

### 1. Создание тестового проекта
1. Перейти на страницу "Проекты"
2. Нажать "Создать проект"
3. Заполнить форму:
   - Название: "Тестовый проект для удаления"
   - Описание: "Проверка каскадного удаления"
4. Сохранить проект
5. Запомнить ID созданного проекта

### 2. Создание интеграций
1. Открыть созданный проект
2. Создать 3 интеграции с любыми параметрами
3. Убедиться, что все интеграции отображаются в списке проекта

### 3. Проверка в БД (до удаления)

**SQLite:**
```bash
sqlite3 dmIntegroff.db "SELECT COUNT(*) FROM integrations WHERE project_id = [ID_ПРОЕКТА];"
```

**MySQL:**
```sql
SELECT COUNT(*) FROM integrations WHERE project_id = [ID_ПРОЕКТА];
```

Ожидаемый результат: 3

### 4. Удаление проекта
1. На странице проекта нажать "Удалить проект"
2. Подтвердить удаление
3. Убедиться, что произошел редирект на список проектов
4. Убедиться, что проект больше не отображается в списке

### 5. Проверка в БД (после удаления)

**SQLite:**
```bash
sqlite3 dmIntegroff.db "SELECT COUNT(*) FROM integrations WHERE project_id = [ID_ПРОЕКТА];"
```

**MySQL:**
```sql
SELECT COUNT(*) FROM integrations WHERE project_id = [ID_ПРОЕКТА];
```

Ожидаемый результат: 0

### 6. Проверка через UI
1. Перейти на страницу "Интеграции"
2. Убедиться, что интеграции удаленного проекта не отображаются

## Ожидаемые результаты
- ✅ Проект успешно удален
- ✅ Все интеграции проекта автоматически удалены из БД
- ✅ Интеграции не отображаются в UI
- ✅ Не возникло ошибок в процессе удаления

## Возможные проблемы

### Интеграции не удалились
**Причина:** Миграция 004 не применена или применена некорректно

**Решение:**
1. Проверить структуру таблицы:
   ```sql
   -- SQLite
   .schema integrations
   
   -- MySQL
   SHOW CREATE TABLE integrations;
   ```
2. Убедиться, что внешний ключ `project_id` имеет `ON DELETE CASCADE`
3. Применить миграцию 004 вручную

### Ошибка при удалении проекта
**Причина:** Нарушение целостности данных или проблемы с БД

**Решение:**
1. Проверить логи приложения
2. Проверить права доступа к БД
3. Убедиться, что foreign keys включены (для SQLite)

## Дополнительные проверки

### Проверка логов запросов
После удаления проекта проверить, что логи запросов интеграций также удалены (если настроено каскадное удаление для логов).

### Проверка производительности
При большом количестве интеграций (100+) проверить время выполнения операции удаления.
