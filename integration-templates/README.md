# Шаблоны интеграций

Эта папка содержит популярные шаблоны для интеграций с различными системами.

## Структура

```
integration-templates/
├── crm/           # CRM системы
├── messengers/    # Мессенджеры и чаты
├── email/         # Email сервисы
├── analytics/     # Системы аналитики
├── payments/      # Платежные системы
├── databases/     # Базы данных
└── other/         # Другие системы
```

## Формат шаблона

Каждый шаблон представляет собой JSON файл со следующей структурой:

```json
{
  "name": "Название системы",
  "description": "Описание того, что делает шаблон",
  "type": "json|text",
  "category": "crm|messengers|email|analytics|payments|databases|other",
  "template": {
    // JSON объект для type: "json"
    // или строка для type: "text"
  }
}
```

## Добавление нового шаблона

1. Создайте JSON файл в соответствующей категории
2. Используйте формат выше
3. Добавьте имя файла (без .json) в массив `templateFiles` в `popular-templates.js`

## Переменные шаблонов

Доступные переменные для использования в шаблонах:

- `{{user.name}}` - Имя пользователя
- `{{user.first_name}}` - Имя
- `{{user.last_name}}` - Фамилия
- `{{user.email}}` - Email
- `{{user.phone}}` - Телефон
- `{{user.id}}` - ID пользователя
- `{{company.name}}` - Название компании
- `{{company.website}}` - Сайт компании
- `{{message.text}}` - Текст сообщения
- `{{event.type}}` - Тип события
- `{{event.data}}` - Данные события
- `{{timestamp}}` - Временная метка
- `{{custom.*}}` - Пользовательские поля

## Примеры использования

### CRM системы
- Создание лидов и контактов
- Обновление информации о клиентах
- Создание сделок

### Мессенджеры
- Отправка уведомлений
- Форматированные сообщения
- Интеграция с ботами

### Email сервисы
- Добавление подписчиков
- Отправка транзакционных писем
- Управление списками рассылки

### Аналитика
- Отправка событий
- Трекинг пользователей
- Метрики и KPI

### Платежи
- Создание платежей
- Обработка транзакций
- Интеграция с платежными шлюзами

### Базы данных
- SQL запросы
- NoSQL документы
- Вставка и обновление данных
