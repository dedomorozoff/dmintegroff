Справка по работе с системой dmIntegroff

🚀 Быстрый старт

Как начать работу с dmIntegroff

  1. Создайте проект - перейдите в раздел "Проекты" и создайте новый проект для группировки ваших интеграций
  2. Добавьте интеграцию - в проекте создайте новую интеграцию, выбрав тип (Bitrix24, amoCRM и т.д.)
  3. Получите webhook URL - после создания интеграции скопируйте уникальный URL для приема данных
  4. Отправьте тестовый запрос - используйте webhook URL для отправки тестовых данных
  5. Настройте маппинг - сопоставьте поля входящих данных с полями целевой системы
  6. Активируйте интеграцию - включите интеграцию для начала обработки реальных данных

📁 Работа с проектами

Что такое проект?

Проект - это контейнер для группировки связанных интеграций. Используйте проекты для организации интеграций по клиентам, отделам или функциональным областям.

Создание проекта

  1. Перейдите в раздел "Проекты"
  2. Нажмите кнопку "Создать проект"
  3. Заполните название и описание
  4. Сохраните проект

Управление проектом

  • Просмотр всех интеграций проекта
  • Добавление новых интеграций
  • Редактирование информации о проекте
  • Удаление проекта (только если нет активных интеграций)

🔗 Работа с интеграциями

Создание интеграции

  1. Выберите проект или создайте новый
  2. Нажмите "Добавить интеграцию"
  3. Укажите название и выберите тип (Bitrix24, amoCRM, Custom)
  4. Введите параметры подключения к целевой системе
  5. Сохраните интеграцию

Настройка маппинга полей

Маппинг позволяет сопоставить поля входящих данных с полями целевой системы:

  1. Отправьте тестовый запрос на webhook URL интеграции
  2. Система автоматически определит структуру данных
  3. В разделе "Настроить" сопоставьте поля источника с полями назначения
  4. Сохраните маппинг

Активация интеграции

После настройки маппинга активируйте интеграцию переключателем. Активная интеграция будет автоматически обрабатывать входящие запросы.

🌐 Работа с Webhook URL

Что такое Webhook URL?

Webhook URL - это уникальный адрес для приема данных от внешних систем. Каждая интеграция имеет свой уникальный URL.

Как использовать Webhook URL

  1. Скопируйте URL из карточки интеграции
  2. Настройте внешнюю систему для отправки данных на этот URL
  3. Данные будут автоматически обрабатываться согласно настроенному маппингу

Безопасность

Webhook URL содержит уникальный токен для защиты от несанкционированного доступа. Не передавайте URL третьим лицам. При необходимости можно сгенерировать новый токен.

📊 Логи и мониторинг

Просмотр логов

В разделе "Логи" вы можете просматривать историю всех запросов:

  • Входящие данные (Request)
  • Исходящие данные (Response)
  • Статус обработки
  • Время выполнения
  • Ошибки при обработке

Фильтрация логов

Используйте фильтры для поиска нужных записей:

  • По интеграции
  • По типу (успех/ошибка)
  • По дате
  • По методу запроса

🔧 Устранение проблем

Интеграция не работает

  • Проверьте, что интеграция активирована
  • Убедитесь, что маппинг полей настроен
  • Проверьте правильность параметров подключения к целевой системе
  • Просмотрите логи для выявления ошибок

Ошибки в логах

  • 401/403 - проверьте токен доступа к целевой системе
  • 404 - проверьте URL целевой системы
  • 500 - ошибка на стороне целевой системы, проверьте её доступность
  • Ошибка маппинга - проверьте соответствие полей

Данные не передаются

  1. Убедитесь, что webhook URL настроен в источнике данных
  2. Проверьте, что интеграция активна
  3. Отправьте тестовый запрос для проверки
  4. Проверьте логи на наличие входящих запросов

ℹ️ Дополнительная информация

Поддерживаемые системы

  • Bitrix24 - CRM и корпоративный портал
  • amoCRM - система управления продажами
  • Custom - любая система с REST API

Ограничения

  • Максимальный размер запроса: 10 МБ
  • Таймаут обработки: 30 секунд
  • Хранение логов: 30 дней
