Webhook подписи (HMAC)

Защита webhook запросов

HMAC подписи обеспечивают аутентичность и целостность данных. Получатель может проверить, что запрос действительно от вас и не был изменен.

Добавлять HMAC подпись к каждому исходящему webhook
Минимум 16 символов. Используется для генерации HMAC подписи
Имя HTTP заголовка для подписи (по умолчанию: X-Webhook-Signature)
SHA-256 рекомендуется для большинства случаев
Формат подписи: X-Webhook-Signature: sha256=5d41402abc4b2a76b9719d911017c592...

Совместимо с GitHub, Stripe, Slack форматами
