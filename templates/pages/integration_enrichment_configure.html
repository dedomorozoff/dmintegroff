🔄 Обогащение данных через GraphQL

Настройка обогащения REST данных через GraphQL запрос

Как это работает:
1. Webhook приходит с базовыми данными
2. Система выполняет GraphQL запрос для получения дополнительных данных
3. Данные объединяются согласно выбранному режиму
4. Обогащенные данные отправляются в Target API

Включить обогащение

GraphQL Endpoint

URL GraphQL API для получения дополнительных данных

GraphQL Query

GraphQL запрос для получения дополнительных данных
Пример: 
query GetUserDetails($userId: ID!) {
  user(id: $userId) {
    name
    email
    phone
    company
    address {
      city
      country
    }
  }
}

Маппинг переменных

Соответствие между GraphQL переменными и полями webhook
Пример: 
{
  "userId": "user_id",
  "orderId": "order.id"
}

Режим объединения данных

Режимы объединения:

Merge: Webhook данные + GraphQL данные (GraphQL перезаписывает совпадающие ключи)
Replace: Только GraphQL данные (webhook данные игнорируются)
Append: Webhook данные + {"enrichment": GraphQL данные}
