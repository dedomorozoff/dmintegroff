ℹ️ Информация о выходах

Множественные выходы позволяют одному webhook отправлять данные на несколько Target API с разными маппингами.

  • Приоритет: Определяет порядок выполнения (меньше = раньше)
  • Условия: Можно настроить условия выполнения для каждого выхода
  • Независимость: Ошибка в одном выходе не влияет на другие
  • Общий образец: Все выходы используют один SamplePayload из интеграции
