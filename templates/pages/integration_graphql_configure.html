GraphQL Query/Mutation

Имя операции для идентификации в логах
Используйте переменные ($var) или placeholders ({{`{{field.path}}`}})
Примеры: 
Query с переменными:
query GetUser($id: ID!) {
  user(id: $id) {
    id
    name
    email
  }
}

Mutation с переменными:
mutation CreateUser($name: String!, $email: String!) {
  createUser(input: {
    name: $name
    email: $email
  }) {
    id
  }
}

Query с placeholders:
query {
  user(id: {{`{{user.id}}`}}) {
    name
    email
  }
}

Маппинг переменных

Как работает маппинг:
Укажите соответствие между GraphQL переменными и полями из webhook payload.
Используйте dot notation для вложенных полей: user.profile.age
JSON объект: {"graphqlVar": "payload.field.path"}
Пример маппинга: 
{
  "id": "user.id",
  "name": "user.name",
  "email": "user.contact.email",
  "age": "user.profile.age"
}

Для webhook payload: {"user": {"id": "123", "name": "John", ...}}
