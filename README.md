# 🚀 GIntegra

**GIntegra** — современная система управления интеграциями REST API на Go. Позволяет легко настраивать связки между различными API, трансформировать данные и автоматически передавать их через вебхуки.

## ✨ Особенности

- 🎨 **Современный UI** - Темная тема с боковым меню и карточным дизайном
- 👥 **Управление пользователями** - Ролевая модель (Администратор / Специалист)
- 🔗 **Конструктор интеграций** - Создание связок Source API → Target API
- 🔄 **Трансформация данных** - Гибкая настройка маппинга полей
- 📡 **Вебхуки** - Автоматическая обработка входящих данных
- 🎧 **Режим прослушивания** - Автоматический захват структуры данных
- 📝 **Логирование** - Просмотр всех запросов и ответов
- 🌐 **Русский интерфейс** - Полностью на русском языке

## 🛠 Технологический стек

- **Backend**: Go 1.20+
- **Web Framework**: Gin
- **ORM**: GORM
- **Database**: SQLite (по умолчанию)
- **Frontend**: Go HTML Templates + Modern CSS

## 🚀 Быстрый старт

> 💡 **Хотите начать быстро?** Смотрите [QUICKSTART.md](QUICKSTART.md) для пошагового руководства за 5 минут!

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/yourusername/gintegra.git
cd gintegra

# Установите зависимости
go mod tidy

# Запустите сервер
go run cmd/server/main.go
```

### Первый вход

Откройте браузер: **http://localhost:8080**

Учетные данные по умолчанию:
- **Логин**: `admin`
- **Пароль**: `admin`

⚠️ **Важно**: Смените пароль после первого входа!

## 📖 Как использовать

### 1. Создание интеграции

1. Перейдите в раздел **"Интеграции"** → **"Создать"**
2. Укажите название и Target API URL
3. Получите уникальный webhook URL

### 2. Настройка маппинга

1. Отправьте тестовый запрос на webhook URL:
   ```bash
   curl -X POST http://localhost:8080/webhook/YOUR_TOKEN \
     -H "Content-Type: application/json" \
     -d '{"name": "John", "email": "john@example.com"}'
   ```

2. Система автоматически захватит структуру данных
3. Настройте маппинг полей в интерфейсе
4. Активируйте интеграцию

### 3. Использование

После активации все запросы на webhook URL будут:
- Трансформироваться согласно маппингу
- Отправляться на Target API
- Логироваться для отладки

## 🔧 Конфигурация

Создайте файл `.env` в корне проекта:

```env
# Секретный ключ для сессий
SESSION_SECRET=your-secret-key-here

# База данных (опционально)
DB_TYPE=sqlite
DB_DSN=gintegra.db

# Порт сервера (опционально)
PORT=8080

# Путь приложения (опционально)
APP_PATH=
```
