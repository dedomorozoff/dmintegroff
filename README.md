# dmIntegroff

**dmIntegroff** — современная система управления интеграциями REST API на Go. Позволяет легко настраивать связки между различными API, трансформировать данные и автоматически передавать их через вебхуки.

## ✨ Ключевые особенности

### 🤖 AI-Ассистент (В разработке)
- **Автоматическое создание интеграций** - опишите задачу, AI создаст готовую интеграцию
- **Умный анализ данных** - автоматическое определение структуры и маппинга
- **База знаний API** - поддержка популярных сервисов (Slack, Telegram, CRM)
- **Демо режим** - изучайте возможности без настройки API ключей

### 🔗 Интеграции
- **Множественные выходы** - один webhook → несколько Target API
- **Поддержка форматов** - JSON, XML, form-data, plain text
- **Трансформация данных** - гибкое маппинг полей и кастомные шаблоны
- **Тестирование** - встроенные инструменты для отладки
- **Проекты** - группировка интеграций для лучшей организации

### 🔐 Аутентификация
- **OAuth 2.0** - автоматическое получение и обновление токенов
- **Bearer Token** - поддержка статических токенов
- **Basic Auth** - HTTP базовая аутентификация
- **GraphQL** - полная поддержка GraphQL API

### 📊 Мониторинг
- **Аналитика в реальном времени** - графики запросов и статистика
- **Детальные логи** - история всех запросов с фильтрацией
- **Экспорт данных** - CSV/JSON экспорт для анализа
- **Метрики Prometheus** - интеграция с системами мониторинга

## 🚀 Быстрый старт

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/dedomorozoff/dmintegroff.git
cd dmIntegroff

# Установите зависимости
go mod tidy

# Скопируйте конфигурацию
cp .env.example .env

# Запустите сервер (режим разработки)
go run cmd/server/main.go

# Или соберите production версию с встроенными файлами
.\build-embedded.bat
.\dmintegroff.exe
```

### Первый вход

Откройте браузер: **http://localhost:8080**

Учетные данные по умолчанию:
- **Логин**: `admin`
- **Пароль**: `admin`

⚠️ **Важно**: Смените пароль после первого входа!

## 🛠 Технологический стек

- **Backend**: Go 1.25+, Gin Web Framework, go:embed для встраивания ресурсов
- **Database**: GORM (SQLite/MySQL)
- **Frontend**: Go HTML Templates, Modern CSS, Vanilla JavaScript
- **Cache**: Redis (опционально)
- **Monitoring**: Prometheus, structured logging
- **Authentication**: Session-based с bcrypt

## 🔧 Сборка и деплой

### Режимы сборки

**Development режим** (быстрая разработка):
```bash
# Запуск с файловой системой (изменения шаблонов видны сразу)
.\run-dev.bat
# или
set USE_EMBEDDED_FILES=false
go run cmd/server/main.go
```

**Production режим** (встроенные файлы):
```bash
# Сборка с go:embed (все ресурсы встроены в .exe)
.\build-embedded.bat

# Запуск автономного исполняемого файла
.\dmintegroff.exe
```

### Преимущества go:embed
- ✅ **Единый файл** - все статические ресурсы встроены в бинарник
- ✅ **Простой деплой** - нужно скопировать только dmintegroff.exe  
- ✅ **Безопасность** - файлы не могут быть изменены извне
- ✅ **Производительность** - быстрая загрузка из памяти

Подробнее: [docs/GO_EMBED_GUIDE.md](docs/GO_EMBED_GUIDE.md)
