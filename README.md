**dmIntegroff** — система управления интеграциями REST API на Go. Позволяет легко настраивать связки между различными API, трансформировать данные и автоматически передавать их через вебхуки.

## Особенности

### Интерфейс
- **Современный UI** - Темная тема с боковым меню и карточным дизайном
- **Адаптивный дизайн** - Работает на всех устройствах
- **Русский интерфейс** - Полностью на русском языке
- **Интерактивная статистика** - График запросов за 30 дней с визуализацией
- **Панель управления** - Обзор всех интеграций и активности в реальном времени

### Интеграции
- **🤖 AI-создание интеграций** - Автоматическое создание интеграций с помощью ИИ
- **Конструктор интеграций** - Создание связок Source API → Target API
- **Проекты** - Группировка интеграций по проектам для лучшей организации
- **Режим прослушивания** - Автоматический захват структуры данных
- **Трансформация данных** - Гибкая настройка маппинга полей
- **Активация/Деактивация** - Управление состоянием интеграций
- **Переопределение маппинга** - Изменение настроек на лету

### AI Помощник
- **Умное создание интеграций** - Опишите задачу, AI создаст готовую интеграцию
- **Анализ данных** - Автоматическое определение типов полей и структуры
- **Генерация маппинга** - AI создает оптимальный маппинг на основе данных
- **Популярные сценарии** - Готовые шаблоны для Slack, Telegram, CRM и других
- **Поддержка OpenRouter** - Доступ к множеству AI моделей через единый API
- **Объяснения AI** - Подробные пояснения созданных интеграций

### Обработка данных
- **Вебхуки** - Автоматическая обработка входящих данных
- **Валидация JSON** - Проверка корректности данных с кнопкой "Проверить"
- **Подсветка синтаксиса** - Цветной JSON с подсветкой плейсхолдеров
- **Автоформатирование** - Кнопка "Автоотступы" для красивого JSON
- **Кастомные JSON шаблоны** - Полный контроль над структурой с `{{field.path}}`
- **Wildcard для массивов** - `{{array.*}}` для копирования массивов неизвестной длины
- **Копирование полей** - Иконки для быстрого копирования плейсхолдеров

### Тестирование и отладка
- **Тестовые вебхуки** - Создание временных вебхуков для отладки (аналог webhook.site)
- **Просмотр в реальном времени** - Все запросы отображаются с обновлением каждые 2 секунды
- **Детальная информация** - Заголовки, тело запроса, query параметры, IP адрес
- **Автоматическое копирование** - URL вебхука копируется в буфер обмена
- **Тестовые запросы** - Отправка тестового запроса прямо со страницы
- **Временные вебхуки** - Автоматическое истечение через 24 часа

### Логирование и мониторинг
- **Умное логирование** - Автоматическое ограничение до 50 записей (не засоряет БД)
- **Отображение заголовков** - HTTP заголовки запросов с подсветкой JSON
- **Автообновление логов** - Обновление каждые 15 секунд
- **Логирование ошибок** - Все ошибки попадают в dmIntegroff.log
- **Визуальное выделение** - Ошибки выделяются красным
- **Статистика запросов** - График обработанных запросов за последние 30 дней
- **Последняя активность** - Отображение последних 10 операций в реальном времени

### Управление
- **Ролевая модель** - Администратор / Специалист
- **Смена пароля** - Безопасная смена пароля через интерфейс настроек
- **CLI инструмент** - Администрирование через командную строку
- **Миграции БД** - Автоматическое создание структуры
- **Сброс пароля** - Восстановление доступа через CLI
- **Демо-режим** - Автоматическая регистрация временных пользователей через GET-параметры (см. `docs/DEMO_MODE.md`)

## Как использовать

### 1. Создание интеграции

1. Перейдите в раздел **"Интеграции"** → **"Создать"**
2. Укажите название и Target API URL
3. Получите уникальный webhook URL

### 2. Настройка трансформации данных

1. Отправьте тестовый запрос на webhook URL:
 ```bash
 curl -X POST http://localhost:8080/webhook/YOUR_TOKEN \
-H "Content-Type: application/json" \
-d '{"name": "John", "email": "john@example.com"}'
 ```

2. Система автоматически захватит структуру данных
3. Выберите режим трансформации:
- **Простой маппинг** - переименование полей
- **Кастомный шаблон** - создание собственной JSON структуры с подстановкой значений через `{{field.path}}`
4. Настройте трансформацию в интерфейсе
5. Активируйте интеграцию

> **Подробнее о шаблонах:** [docs/TEMPLATE_GUIDE.md](docs/TEMPLATE_GUIDE.md)

### 3. Организация в проекты (опционально)

1. Создайте проект для группировки интеграций
2. Добавьте интеграции в проект
3. Управляйте всеми интеграциями проекта из одного места

> **Подробнее о проектах:** [docs/QUICK_START_PROJECTS.md](docs/QUICK_START_PROJECTS.md)

### 4. Использование

После активации все запросы на webhook URL будут:
- Трансформироваться согласно маппингу
- Отправляться на Target API
- Логироваться для отладки

## Конфигурация

Создайте файл `.env` в корне проекта:

```env
# dmIntegroff Configuration

# ===================
# Server Settings
# ===================
PORT=8080
GIN_MODE=debug

# ===================
# Database Settings
# ===================
# Options: sqlite, mysql
DB_TYPE=sqlite

# For SQLite (default):
DB_DSN=dmintegroff.db

# For MySQL (uncomment and configure):
# DB_DSN=user:password@tcp(localhost:3306)/dmintegroff?charset=utf8mb4&parseTime=True&loc=Local

# ===================
# Security Settings
# ===================
# IMPORTANT: Change this in production!
SESSION_SECRET=your-super-secret-key-change-this-in-production

# Custom application path (optional)
# Example: /api/v1 or leave empty for root
APP_PATH=

# ===================
# Logging Settings
# ===================
# Options: debug, info, warn, error
LOG_LEVEL=info

# Log file path (leave empty for stdout only)
LOG_FILE=dmintegroff.log

# ===================
# Development Settings
# ===================
# Enable debug mode (set to false in production)
DEBUG=true
```

> **Совет**: Настройки можно редактировать вручную в файле `.env`. Для применения изменений требуется перезапуск сервера.

### Аутентификация
- **OAuth 2.0** - Автоматическое получение и обновление токенов
- **Bearer Token** - Поддержка статических токенов
- **Basic Auth** - HTTP базовая аутентификация
- **Тестирование OAuth** - Проверка настроек перед активацией

### GraphQL Support
- **GraphQL Client** - Отправка queries и mutations к GraphQL API
- **Schema Introspection** - Автоматическое получение схемы API
- **Variable Mapping** - Маппинг полей webhook → GraphQL переменные
- **Placeholder Support** - Динамическая подстановка {{field.path}}
- **Testing** - Тест подключения и выполнения запросов
- **REST + GraphQL** - Обогащение REST данных через GraphQL (через оркестратор)
