# 🚀 dmIntegroff

**dmIntegroff** — современная система управления интеграциями REST API на Go. Позволяет легко настраивать связки между различными API, трансформировать данные и автоматически передавать их через вебхуки.

## ✨ Особенности

### 🎨 Интерфейс
- **Современный UI** - Темная тема с боковым меню и карточным дизайном
- **Адаптивный дизайн** - Работает на всех устройствах
- **Русский интерфейс** - Полностью на русском языке

### 🔗 Интеграции
- **Конструктор интеграций** - Создание связок Source API → Target API
- **Проекты** - Группировка интеграций по проектам для лучшей организации
- **Режим прослушивания** - Автоматический захват структуры данных
- **Трансформация данных** - Гибкая настройка маппинга полей
- **Активация/Деактивация** - Управление состоянием интеграций
- **Переопределение маппинга** - Изменение настроек на лету

### 📡 Обработка данных
- **Вебхуки** - Автоматическая обработка входящих данных
- **Валидация JSON** - Проверка корректности данных
- **Подсветка синтаксиса** - Удобный просмотр JSON

### 📝 Логирование
- **Умное логирование** - Только тестовые запросы и ошибки (не засоряет БД)
- **Отображение заголовков** - HTTP заголовки запросов с подсветкой JSON
- **Автообновление логов** - Обновление каждые 15 секунд
- **Логирование ошибок** - Все ошибки попадают в dmIntegroff.log
- **Визуальное выделение** - Ошибки выделяются красным

### 👥 Управление
- **Ролевая модель** - Администратор / Специалист
- **CLI инструмент** - Администрирование через командную строку
- **Миграции БД** - Автоматическое создание структуры
- **Сброс пароля** - Восстановление доступа

## 🛠 Технологический стек

- **Backend**: Go 1.20+
- **Web Framework**: Gin
- **ORM**: GORM
- **Database**: SQLite (по умолчанию)
- **Frontend**: Go HTML Templates + Modern CSS

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/dedomorozoff/dmintegroff.git
cd dmIntegroff

# Установите зависимости
go mod tidy

# Запустите сервер
go run cmd/server/main.go
```

### Первый вход

Откройте браузер: **http://localhost:8080**

Учетные данные по умолчанию:
- **Логин**: `admin`
- **Пароль**: `admin`

⚠️ **Важно**: Смените пароль после первого входа!

## 📖 Как использовать

### 1. Создание интеграции

1. Перейдите в раздел **"Интеграции"** → **"Создать"**
2. Укажите название и Target API URL
3. Получите уникальный webhook URL

### 2. Настройка маппинга

1. Отправьте тестовый запрос на webhook URL:
   ```bash
   curl -X POST http://localhost:8080/webhook/YOUR_TOKEN \
     -H "Content-Type: application/json" \
     -d '{"name": "John", "email": "john@example.com"}'
   ```

2. Система автоматически захватит структуру данных
3. Настройте маппинг полей в интерфейсе
4. Активируйте интеграцию

### 3. Организация в проекты (опционально)

1. Создайте проект для группировки интеграций
2. Добавьте интеграции в проект
3. Управляйте всеми интеграциями проекта из одного места

> 💡 **Подробнее о проектах:** [docs/QUICK_START_PROJECTS.md](docs/QUICK_START_PROJECTS.md)

### 4. Использование

После активации все запросы на webhook URL будут:
- Трансформироваться согласно маппингу
- Отправляться на Target API
- Логироваться для отладки

## 🔧 Конфигурация

Создайте файл `.env` в корне проекта:

```env
# Секретный ключ для сессий
SESSION_SECRET=your-secret-key-here

# База данных (опционально)
DB_TYPE=sqlite
DB_DSN=dmIntegroff.db

# Порт сервера (опционально)
PORT=8080

# Путь приложения (опционально)
APP_PATH=
```
