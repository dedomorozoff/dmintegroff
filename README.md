# GIntegra

**GIntegra** — это система полуавтоматической интеграции REST API, разработанная на Go. Она позволяет специалистам настраивать связки между различными API, трансформировать данные и автоматически передавать их через вебхуки.

## Особенности

*   **Управление пользователями**: Ролевая модель (Администратор / Специалист).
*   **Конструктор интеграций**: Создание связок Source API -> Target API.
*   **Трансформация данных**: Гибкая настройка маппинга полей через JSON.
*   **Вебхуки**: Автоматическая обработка входящих данных и отправка в целевую систему.
*   **Интерфейс**: Простой и понятный веб-интерфейс на русском языке.

## Технологический стек

*   **Язык**: Golang
*   **Веб-фреймворк**: Gin
*   **ORM**: GORM
*   **База данных**: SQLite (по умолчанию) или MySQL.
*   **Frontend**: Go HTML Templates + CSS.

## Установка и запуск

### Предварительные требования

*   Go 1.20 или выше.

### Запуск

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/yourusername/gintegra.git
    cd gintegra
    ```

2.  Установите зависимости:
    ```bash
    go mod tidy
    ```

3.  Запустите сервер:
    ```bash
    go run cmd/server/main.go
    ```

4.  Откройте браузер по адресу [http://localhost:8080](http://localhost:8080).

### Вход в систему

При первом запуске автоматически создается администратор:
*   **Логин**: `admin`
*   **Пароль**: `admin`

## Конфигурация

Система поддерживает настройку через переменные окружения (или может быть доработана для использования `.env`):

*   `DB_TYPE`: Тип базы данных (`sqlite` или `mysql`). По умолчанию `sqlite`.
*   `DB_DSN`: Строка подключения к БД.
    *   Для SQLite: путь к файлу (по умолчанию `gintegra.db`).
    *   Для MySQL: `user:password@tcp(127.0.0.1:3306)/dbname?charset=utf8mb4&parseTime=True&loc=Local`.
