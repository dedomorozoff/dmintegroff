# Быстрый старт с новой схемой миграций

## Для разработчиков

### Новая установка

Просто запустите приложение - GORM автоматически создаст все таблицы:

```bash
cd dmintegroff
go run cmd/server/main.go
```

Или используйте admin CLI:

```bash
go run cmd/admin/main.go
# Выберите "1. Выполнить миграцию базы данных"
```

### Существующая база данных

Если у вас уже есть база данных со старыми миграциями - **ничего делать не нужно!** 

GORM AutoMigrate автоматически добавит недостающие поля и таблицы при запуске.

### Чистая установка (с нуля)

Если хотите начать с чистой базы:

```bash
# Удалите старую БД
rm dmintegroff.db

# Запустите миграцию
go run cmd/admin/main.go
# Выберите "1. Выполнить миграцию базы данных"
```

## Для DevOps / Продакшн

### Автоматическое развертывание

Используйте флаг `-migrate`:

```bash
./dmintegroff -migrate
```

### Ручное развертывание SQL

Если вы предпочитаете ручное управление схемой:

**SQLite:**
```bash
sqlite3 dmintegroff.db < migrations/schema_sqlite.sql
```

**MySQL:**
```bash
mysql -u username -p database_name < migrations/schema_mysql.sql
```
