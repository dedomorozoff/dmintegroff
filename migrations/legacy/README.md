# Legacy Migrations

Эта папка содержит старые пронумерованные файлы миграций, которые были объединены в консолидированные схемы.

## Статус

**Эти файлы больше не используются** и сохранены только для исторической справки.

## Что случилось?

Все миграции были объединены в два основных файла:
- `../schema_sqlite.sql` - для SQLite
- `../schema_mysql.sql` - для MySQL

## Зачем они сохранены?

- Историческая справка
- Понимание эволюции схемы базы данных
- Возможность отследить, когда и какие изменения были внесены

## Для новых установок

**Не используйте эти файлы!** Вместо этого используйте консолидированные схемы из родительской папки.

См. `../README.md` для инструкций по применению схемы.
