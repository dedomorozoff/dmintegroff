# Changelog

Все значимые изменения в проекте dmIntegroff документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### 📝 Изменено - Логирование запросов (2024-11-29)
- **Оптимизация логирования**
  - Убрано логирование всех HTTP запросов в БД
  - Теперь логируются только тестовые запросы (`/test`) и ошибки
  - Значительно уменьшен размер базы данных
- **Отображение заголовков**
  - Добавлено поле `request_headers` в модель `RequestLog`
  - На странице логов теперь отображаются HTTP заголовки
  - Визуальное разделение тела запроса и заголовков
  - Подсветка синтаксиса JSON для заголовков
- **CLI обновления**
  - Добавлена модель `Project` в автоматические миграции
  - CLI теперь автоматически добавляет новые колонки при обновлении
- **Миграции**
  - `migrations/003_add_request_headers.sql` (PostgreSQL)
  - `migrations/003_add_request_headers_sqlite.sql` (SQLite)
  - `migrations/003_add_request_headers_mysql.sql` (MySQL)

### Планируется
- Поддержка OAuth 2.0 для Target API
- Retry механизм с экспоненциальной задержкой
- Webhook подписи (HMAC)
- Экспорт/импорт конфигураций
- Метрики и мониторинг
- Docker образ
- WebSocket для real-time обновлений
