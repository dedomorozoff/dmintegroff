## 🤝 Как приоритизировать задачи

### Критерии оценки:
1. **Влияние на пользователей** (1-5)
2. **Сложность реализации** (1-5)
3. **Риски** (1-5)
4. **Зависимости** (есть/нет)

### Формула приоритета:
```
Приоритет = (Влияние × 2) - Сложность - Риски
```

### Примеры:
- **Исправление багов:** Влияние=5, Сложность=2, Риски=1 → Приоритет=7 (Критический)
- **Новая функция:** Влияние=3, Сложность=4, Риски=2 → Приоритет=0 (Низкий)
- **UI улучшения:** Влияние=4, Сложность=2, Риски=1 → Приоритет=5 (Высокий)
