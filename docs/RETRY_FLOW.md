# Retry механизм - Диаграмма работы

## Общая схема работы

```
┌─────────────────────────────────────────────────────────────┐
│                    Входящий HTTP запрос                      │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│              retryWithBackoff(req, client, config)           │
│  • MaxAttempts: 3                                            │
│  • InitialDelay: 1s                                          │
│  • MaxDelay: 30s                                             │
│  • Multiplier: 2.0                                           │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
                    ┌─────────────────┐
                    │  Попытка #1     │
                    │  (немедленно)   │
                    └─────────────────┘
                              │
                    ┌─────────┴─────────┐
                    │                   │
                    ▼                   ▼
            ┌──────────────┐    ┌──────────────┐

            └──────────────┘    └──────────────┘
                    │                   │
                    │                   ▼
                    │         ┌──────────────────┐
                    │         │ isRetryable?     │
                    │         │ 503 = YES        │
                    │         └──────────────────┘
                    │                   │
                    │                   ▼
                    │         ┌──────────────────┐
                    │         │ Ждем 1 секунду   │
                    │         │ (InitialDelay)   │
                    │         └──────────────────┘
                    │                   │
                    │                   ▼
                    │         ┌──────────────────┐
                    │         │  Попытка #2      │
                    │         └──────────────────┘
                    │                   │
                    │         ┌─────────┴─────────┐
                    │         │                   │
                    │         ▼                   ▼
                    │  ┌──────────────┐    ┌──────────────┐
                    │  │   Успех      │    │   Ошибка     │
                    │  │   200 OK     │    │   503        │
                    │  └──────────────┘    └──────────────┘
                    │         │                   │
                    │         │                   ▼
                    │         │         ┌──────────────────┐
                    │         │         │ Ждем 2 секунды   │
                    │         │         │ (1s * 2^1)       │
                    │         │         └──────────────────┘
                    │         │                   │
                    │         │                   ▼
                    │         │         ┌──────────────────┐
                    │         │         │  Попытка #3      │
                    │         │         │  (последняя)     │
                    │         │         └──────────────────┘
                    │         │                   │
                    │         │         ┌─────────┴─────────┐
                    │         │         │                   │
                    │         │         ▼                   ▼
                    │         │  ┌──────────────┐    ┌──────────────┐
                    │         │  │   Успех      │    │   Ошибка     │

                    │         │  └──────────────┘    └──────────────┘
                    │         │         │                   │
                    ▼         ▼         ▼                   ▼
            ┌──────────────────────────────┐    ┌──────────────────┐
            │   Возврат успешного ответа   │    │  Возврат ошибки  │
            │   resp, nil                  │    │  nil, error      │
            └──────────────────────────────┘    └──────────────────┘
```

## Экспоненциальная задержка

```
Попытка    Формула              Задержка    Накопленная
──────────────────────────────────────────────────────────
1          -                    0s          0s
2          1s * 2^0 = 1s        1s          1s
3          1s * 2^1 = 2s        2s          3s
4          1s * 2^2 = 4s        4s          7s
5          1s * 2^3 = 8s        8s          15s
6          1s * 2^4 = 16s       16s         31s
7          1s * 2^5 = 32s       30s (cap)   61s
```

## Сценарии использования

### Сценарий 1: OAuth2 токен запрос

```
┌──────────────┐
│ Integration  │
│   Service    │
└──────┬───────┘
       │
       │ GetAccessToken(integration)
       ▼
┌──────────────┐
│    OAuth     │
│   Service    │
└──────┬───────┘
       │
       │ fetchNewAccessToken()
       ▼
┌──────────────┐
│    Retry     │
│  Mechanism   │
└──────┬───────┘
       │
       │ retryWithBackoff(req, client, config)
       ▼
┌──────────────┐
│   OAuth2     │
│   Provider   │
└──────┬───────┘
       │
       │ 200 OK + access_token
       ▼
┌──────────────┐
│   Database   │
│  (save token)│
└──────────────┘
```

## Матрица решений

```
HTTP Status    Retryable?    Причина
─────────────────────────────────────────────────────────
200 OK         ❌ Нет        Успех
201 Created    ❌ Нет        Успех
400 Bad Req    ❌ Нет        Постоянная ошибка клиента
401 Unauth     ❌ Нет        Проблема с аутентификацией
403 Forbidden  ❌ Нет        Нет доступа
404 Not Found  ❌ Нет        Ресурс не существует
429 Too Many   ✅ Да         Rate limit, временно
500 Internal   ✅ Да         Временная ошибка сервера
502 Bad Gate   ✅ Да         Проблема с прокси
503 Unavail    ✅ Да         Сервис временно недоступен
504 Timeout    ✅ Да         Таймаут шлюза
```

## Заключение

Retry механизм с экспоненциальной задержкой обеспечивает:
- ✅ Автоматическое восстановление после временных сбоев
- ✅ Защиту от перегрузки внешних API
- ✅ Прозрачное логирование всех попыток
- ✅ Гибкую настройку под разные сценарии
- ✅ Высокую надежность интеграций
