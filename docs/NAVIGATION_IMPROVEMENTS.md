# Улучшения навигации между страницами интеграции

## Обзор

Добавлены кнопки быстрого перехода между страницей редактирования интеграции и страницей настройки маппинга для более удобной работы.

## Новые кнопки навигации

### 1. На странице редактирования интеграции

**Расположение:** 
- В заголовке страницы (справа вверху)
- В нижней части формы (рядом с кнопкой "Сохранить")

**Кнопка:** "Настроить маппинг"
- Иконка: shuffle (🔀)
- Цвет: Primary (синий)
- Переход: `/integrations/{id}/configure`

**Условия отображения:**
- Кнопка показывается только если интеграция НЕ в режиме `listening`
- Для интеграций в режиме `listening` сначала нужно получить данные

### 2. На странице настройки маппинга

**Расположение:**
- В заголовке страницы (справа вверху)
- В нижней части формы (рядом с кнопкой "Сохранить")

**Кнопка:** "Настройки интеграции"
- Иконка: settings (⚙️)
- Цвет: Secondary (серый) в заголовке, Primary (синий) внизу
- Переход: `/integrations/{id}/edit`

**Условия отображения:**
- Кнопка показывается всегда

## Преимущества

### Быстрый доступ
- Не нужно возвращаться к списку интеграций
- Прямой переход между связанными страницами
- Экономия времени при настройке

### Логичный workflow
1. Создать интеграцию → Редактирование
2. Настроить параметры (API, аутентификация, заголовки)
3. Перейти к маппингу → Настройка маппинга
4. Настроить трансформацию данных
5. При необходимости вернуться к настройкам → Редактирование

### Улучшенный UX
- Интуитивная навигация
- Меньше кликов для выполнения задач
- Контекстные переходы

## Примеры использования

### Сценарий 1: Настройка новой интеграции
1. Создать интеграцию
2. Настроить Target API и аутентификацию
3. Нажать "Настроить маппинг" (в заголовке или внизу)
4. Настроить трансформацию данных
5. Сохранить и активировать

### Сценарий 2: Изменение существующей интеграции
1. Открыть интеграцию для редактирования
2. Изменить URL или добавить заголовки
3. Нажать "Настроить маппинг" для проверки
4. Убедиться, что маппинг корректен
5. Вернуться через "Настройки интеграции" если нужно

### Сценарий 3: Отладка интеграции
1. Открыть настройку маппинга
2. Проверить трансформацию данных
3. Перейти в "Настройки интеграции"
4. Проверить заголовки и аутентификацию
5. Вернуться к маппингу для финальной проверки

## Технические детали

### Кнопки в заголовке
```html
<div style="display: flex; justify-content: space-between; align-items: flex-start; gap: 1rem; flex-wrap: wrap;">
    <div>
        <h1>Заголовок</h1>
        <p>Описание</p>
    </div>
    <a href="/integrations/{{ .integration.ID }}/configure" class="btn btn-secondary" style="white-space: nowrap;">
        <i data-lucide="shuffle"></i> Настроить маппинг
    </a>
</div>
```

### Кнопки внизу формы
```html
<div style="display: flex; gap: 1rem; margin-top: 2rem; flex-wrap: wrap;">
    <button type="submit" class="btn btn-success">Сохранить</button>
    <a href="/integrations/{{ .integration.ID }}/edit" class="btn btn-primary">
        <i data-lucide="settings"></i> Настройки интеграции
    </a>
    <a href="/integrations" class="btn btn-secondary">Отмена</a>
</div>
```

### Условное отображение
```html
{{ if ne .integration.Mode "listening" }}
<a href="/integrations/{{ .integration.ID }}/configure" class="btn btn-primary">
    <i data-lucide="shuffle"></i> Настроить маппинг
</a>
{{ end }}
```

## Адаптивность

- Кнопки используют `flex-wrap: wrap` для корректного отображения на мобильных устройствах
- `white-space: nowrap` предотвращает перенос текста внутри кнопок
- Иконки Lucide автоматически инициализируются

## Совместимость

- Работает со всеми типами интеграций (REST, GraphQL)
- Совместимо с существующими кнопками (GraphQL, Enrichment)
- Не конфликтует с другими элементами интерфейса
