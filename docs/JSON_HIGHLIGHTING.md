# 🎨 Подсветка синтаксиса JSON

## Обзор

В dmIntegroff реализована подсветка синтаксиса JSON для удобного редактирования шаблонов и данных.

## Цветовая схема (One Dark)

### Элементы JSON

| Элемент | Цвет | Пример |
|---------|------|--------|
| **Строки** | 🟢 Зеленый (#98c379) | `"Hello World"` |
| **Числа** | 🟠 Оранжевый (#d19a66) | `42`, `3.14` |
| **Булевы** | 🔵 Голубой (#56b6c2) | `true`, `false` |
| **null** | 🟣 Фиолетовый (#c678dd) | `null` |
| **Ключи** | 🔴 Красный (#e06c75) | `"name":` |
| **Плейсхолдеры** | 💙 Синий (#61afef) | `{{user.name}}` |

### Специальная подсветка плейсхолдеров

Плейсхолдеры `{{field.path}}` выделяются:
- **Синим цветом** (#61afef)
- **Жирным шрифтом**
- **Полупрозрачным фоном** для лучшей видимости

## Примеры

### Простой JSON
```json
{
  "name": "Иван",
  "age": 30,
  "active": true,
  "balance": null
}
```

**Подсветка:**
- `"name"` - красный (ключ)
- `"Иван"` - зеленый (строка)
- `30` - оранжевый (число)
- `true` - голубой (булево)
- `null` - фиолетовый

### JSON с плейсхолдерами
```json
{
  "userName": "{{user.name}}",
  "userAge": {{user.age}},
  "isActive": {{user.active}}
}
```

**Подсветка:**
- `"userName"` - красный (ключ)
- `{{user.name}}` - синий с фоном (плейсхолдер в строке)
- `{{user.age}}` - синий с фоном (плейсхолдер число)
- `{{user.active}}` - синий с фоном (плейсхолдер булево)

### Сложная структура
```json
{
  "customer": {
    "fullName": "{{user.profile.name}}",
    "contacts": {
      "email": "{{user.email}}",
      "phone": "{{user.phone}}"
    },
    "stats": {
      "orders": {{user.orders.count}},
      "verified": {{user.verified}}
    }
  },
  "metadata": {
    "source": "webhook",
    "version": "1.0"
  }
}
```

## Где используется подсветка

### 1. Редактор JSON шаблонов
- Страница настройки интеграции
- Секция "Кастомный JSON шаблон"
- Большое текстовое поле для ввода шаблона

### 2. Редактор Sample Payload
- Страница настройки интеграции
- Кнопка "Редактировать JSON"
- Редактирование образца данных

## Технические детали

### Реализация
- **Без внешних библиотек** - чистый JavaScript
- **Легковесная** - ~5KB кода
- **Быстрая** - обновление в реальном времени
- **Адаптивная** - работает на всех устройствах

### Файлы
```
static/js/json-highlight.js      - JavaScript для подсветки
static/css/json-highlight.css    - Стили для подсветки
```

### Принцип работы
1. Textarea становится прозрачным
2. Под ним отображается div с подсвеченным текстом
3. При вводе текст обновляется в реальном времени
4. Курсор остается видимым в textarea

### Классы CSS
```css
.json-editor          - Textarea для ввода
.json-preview         - Div с подсветкой
.json-string          - Строки
.json-number          - Числа
.json-boolean         - Булевы значения
.json-null            - null
.json-key             - Ключи объектов
.json-placeholder     - Плейсхолдеры в строках
.json-placeholder-raw - Плейсхолдеры вне строк
```

## Особенности

### ✅ Преимущества
- Легко читать JSON
- Плейсхолдеры выделяются
- Ошибки видны сразу
- Не мешает вводу текста
- Работает без задержек

### ⚠️ Ограничения
- Не проверяет валидность JSON (для этого есть кнопка "Проверить шаблон")
- Не показывает номера строк (можно добавить при необходимости)
- Не поддерживает автодополнение (можно добавить в будущем)

## Настройка

### Изменение цветов
Отредактируйте файл `static/css/json-highlight.css`:

```css
/* Строки */
.json-string {
    color: #98c379; /* Измените на свой цвет */
}

/* Плейсхолдеры */
.json-placeholder {
    color: #61afef;
    background: rgba(97, 175, 239, 0.1);
}
```

### Добавление новых элементов
В файле `static/js/json-highlight.js` метод `highlight()`:

```javascript
// Добавьте свою регулярку
text = text.replace(/ваш_паттерн/g, '<span class="ваш-класс">$1</span>');
```

## Примеры использования

### Базовый пример
```html
<div class="json-editor-container">
    <textarea id="myEditor" class="json-editor"></textarea>
    <div id="myEditor_preview" class="json-preview"></div>
</div>

<script>
    new JSONHighlighter('myEditor', 'myEditor_preview');
</script>
```

### С автоинициализацией
```html
<textarea class="json-editor" id="autoEditor"></textarea>

<!-- Автоматически инициализируется при загрузке страницы -->
```
