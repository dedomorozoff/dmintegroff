# Тестирование множественных выходов

## Быстрый тест

### 1. Создание интеграции с выходами

```bash
# 1. Создайте интеграцию через UI
# 2. Отправьте тестовый webhook
curl -X POST http://localhost:8080/webhook/YOUR_TOKEN \
  -H "Content-Type: application/json" \
  -d '{"user": "John", "email": "john@example.com", "amount": 1000}'

# 3. Перейдите в "Управление выходами"
# 4. Создайте несколько выходов
```

### 2. Настройка выходов

**Выход 1: JSON API**
- Target: `http://localhost:8080/webhook/test`
- Шаблон:
```json
{
  "name": "{{user}}",
  "contact": "{{email}}"
}
```

**Выход 2: XML API**
- Target: `http://localhost:8080/webhook/test`
- Тип: XML
- Шаблон:
```xml
<user>
  <name>{{user}}</name>
  <email>{{email}}</email>
</user>
```

### 3. Тестирование

1. Нажмите "Протестировать" для каждого выхода
2. Проверьте результаты трансформации
3. Активируйте интеграцию
4. Отправьте реальный webhook
5. Проверьте логи

## Проверка параллельного выполнения

Создайте 3+ выходов и проверьте логи - все должны выполниться одновременно.
