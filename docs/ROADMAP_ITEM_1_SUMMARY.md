# ✅ Реализация: Использование запроса как образца данных

**Дата:** 8 декабря 2024  
**Статус:** Реализовано  
**Приоритет:** Высокий

## Что реализовано

Добавлена возможность использовать запрос из тестового webhook в качестве образца данных для настройки маппинга интеграции.

## Основные компоненты

### Backend (Go)

**Файл:** `internal/controllers/webhook_test_controller.go`

Новая функция `UseRequestAsSample`:
- Принимает token webhook и ID запроса
- Проверяет права доступа пользователя
- Сохраняет body запроса в `SamplePayload` интеграции
- Возвращает URL для редиректа

**Файл:** `internal/routes/routes.go`

Новый endpoint:
```go
POST /api/webhook-test/:token/use-as-sample/:request_id
```

### Frontend (HTML + JavaScript)

**Файл:** `templates/pages/webhook_test.html`

Добавлено:
1. Кнопка "Использовать как образец данных" в деталях каждого запроса
2. Модальное окно для выбора интеграции
3. JavaScript функции:
   - `showUseAsSampleModal()` - открытие модального окна
   - `closeUseAsSampleModal()` - закрытие модального окна
   - `useAsSample()` - отправка запроса на сохранение
4. Стили для модального окна и списка интеграций

## Пользовательский сценарий

1. Пользователь создает тестовый webhook
2. Отправляет тестовый запрос с данными
3. Нажимает "Использовать как образец данных"
4. Выбирает интеграцию из списка
5. Автоматически перенаправляется на страницу настройки маппинга
6. Образец данных уже заполнен и готов к использованию

## Преимущества

✅ **Экономия времени** - не нужно копировать JSON вручную  
✅ **Удобство** - один клик вместо нескольких действий  
✅ **Безопасность** - проверка прав доступа на всех уровнях  
✅ **Гибкость** - можно использовать один запрос для нескольких интеграций  

## Технические детали

### API Request
```json
POST /api/webhook-test/:token/use-as-sample/:request_id
Content-Type: application/json

{
  "integration_id": 1
}
```

### API Response (Success)
```json
{
  "status": "success",
  "message": "Request saved as sample payload",
  "integration_id": 1,
  "redirect_url": "/integrations/1/configure"
}
```

### API Response (Error)
```json
{
  "error": "Webhook not found"
}
```
