# Быстрый старт - Администрирование

## Сброс пароля администратора

```bash
go run cmd/admin/main.go -reset-password
```

Введите новый пароль когда будет предложено.

## Генерация случайного URL (для безопасности)

```bash
go run cmd/admin/main.go -generate-secret
```

Скопируйте сгенерированный путь и добавьте в `.env`:
```
APP_PATH=/сгенерированный_путь
```

Перезапустите сервер. Теперь приложение доступно только по этому пути.

## Интерактивный режим

```bash
go run cmd/admin/main.go
```

Выберите нужное действие из меню.
