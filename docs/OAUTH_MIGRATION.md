# 🔄 Миграция на OAuth 2.0

## Для существующих пользователей

Если вы обновляете dmIntegroff с предыдущей версии, новые поля OAuth будут автоматически добавлены в базу данных при запуске.

## Что изменилось

### Новые возможности
- ✅ OAuth 2.0 аутентификация
- ✅ Bearer Token поддержка
- ✅ Basic Auth поддержка
- ✅ Автоматическое обновление токенов
- ✅ Тестирование OAuth настроек

### Обратная совместимость
- ✅ Все существующие интеграции продолжат работать
- ✅ По умолчанию используется "Без аутентификации"
- ✅ Никаких изменений в API или структуре данных

## Процесс обновления

### 1. Остановите сервер
```bash
# Если запущен через systemd
sudo systemctl stop dmintegroff

# Или просто Ctrl+C если запущен вручную
```

### 2. Обновите код
```bash
cd dmintegroff
git pull origin main
go mod tidy
```

### 3. Запустите сервер
```bash
go run cmd/server/main.go

# Или через systemd
sudo systemctl start dmintegroff
```

### 4. Проверьте миграцию
При запуске вы увидите:
```
Database connected successfully
Database migration completed
```

Это означает, что новые поля OAuth успешно добавлены.

## Добавление OAuth к существующим интеграциям

1. Перейдите в **Интеграции**
2. Нажмите **Редактировать** на нужной интеграции
3. Прокрутите до раздела **"Аутентификация Target API"**
4. Выберите тип аутентификации
5. Заполните необходимые поля
6. Нажмите **"Тест OAuth"** (для OAuth 2.0)
7. Сохраните изменения

## Проверка работы

### Тест 1: Существующие интеграции
```bash
# Отправьте тестовый запрос на существующую интеграцию
curl -X POST http://localhost:8080/webhook/YOUR_TOKEN \
  -H "Content-Type: application/json" \
  -d '{"test": "data"}'
```

Должно работать как раньше.

### Тест 2: OAuth интеграция
1. Создайте новую интеграцию с OAuth
2. Настройте OAuth параметры
3. Нажмите "Тест OAuth"
4. Отправьте webhook запрос
5. Проверьте логи

## Откат (если нужно)

Если возникли проблемы:

### SQLite
```bash
# Удалите новые колонки (опционально)
sqlite3 dmintegroff.db
ALTER TABLE integrations DROP COLUMN auth_type;
# ... и так далее для всех OAuth полей
```

### MySQL
```bash
mysql -u user -p dmintegroff
ALTER TABLE integrations DROP COLUMN auth_type;
# ... и так далее для всех OAuth полей
```

Затем вернитесь к предыдущей версии кода:
```bash
git checkout [previous-version]
go run cmd/server/main.go
```
