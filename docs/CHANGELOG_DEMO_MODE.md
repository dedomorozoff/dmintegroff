# Changelog - Демо-режим

## Версия: Демо-режим (2024-12-01)

### 🎉 Новые возможности

#### Демо-режим
- Автоматическая регистрация временных пользователей через GET-параметры
- Защита секретным ключом (`DEMO_SECRET`)
- Автоматическое заполнение полей логина и пароля
- Срок действия демо-пользователей: 24 часа
- Автоматическая очистка истекших демо-пользователей

#### Ограничения безопасности
- Демо-пользователи могут отправлять вебхуки только на разрешенный URL (`DEMO_TARGET_URL`)
- Демо-пользователи имеют роль "specialist" (не admin)
- Валидация target URL при обработке вебхуков

### 📝 Изменения в коде

#### Модели
- `internal/models/user.go`
  - Добавлено поле `IsDemo` (bool) - флаг демо-пользователя
  - Добавлено поле `ExpiresAt` (*time.Time) - время истечения

#### Контроллеры
- `internal/controllers/auth_controller.go`
  - Функция `LoginPage()` - обработка GET-параметров для демо-режима
  - Функция `RegisterDemoUser()` - автоматическая регистрация демо-пользователя
  - Функция `CleanupExpiredDemoUsers()` - очистка истекших пользователей

#### Сервисы
- `internal/services/integration_service.go`
  - Функция `ValidateDemoMode()` - проверка ограничений для демо-пользователей
  - Обновлена `ProcessWebhook()` - добавлена валидация демо-режима

#### Шаблоны
- `templates/pages/login.html`
  - Автозаполнение полей username и password
  - Уведомление об успешной регистрации демо-пользователя

```env

```

### 🔒 Безопасность

#### Меры безопасности
- Демо-пользователи не могут получить роль admin
- Ограничение на target URL для демо-пользователей
- Автоматическое удаление через 24 часа
- Защита регистрации секретным ключом

#### Рекомендации
- Используйте сложный `DEMO_SECRET`
- Не включайте `DEMO_MODE=true` в продакшене
- Регулярно проверяйте список демо-пользователей

### 📖 Использование

#### Пример URL для регистрации
```
http://localhost:8080/login?demo_key=YOUR_SECRET&username=demo&password=demo123
```

#### Параметры
- `demo_key` - секретный ключ из DEMO_SECRET
- `username` - имя пользователя
- `password` - пароль
