# Безопасность HTTP прокси

## Обзор

HTTP прокси в dmIntegroff обеспечивает безопасную отправку запросов на внешние API, предотвращая потенциальные угрозы безопасности.

## Правила безопасности

### ✅ Разрешенные запросы

1. **Внешние публичные API**
   - Любые домены в интернете (example.com, api.service.com)
   - Тестовые сервисы (httpbin.org, postman-echo.com)
   - Публичные API сервисов

2. **Собственный сервер dmIntegroff**
   - Тестовые вебхуки на том же сервере
   - Локальные endpoint'ы dmIntegroff
   - Автоматическое определение по хосту и порту

### ❌ Заблокированные запросы

1. **Локальные адреса**
   - localhost (кроме собственного сервера)
   - 127.0.0.1 (кроме собственного сервера)
   - ::1 (IPv6 localhost)

2. **Приватные сети**
   - 192.168.x.x (домашние сети)
   - 10.x.x.x (корпоративные сети)
   - 172.16.x.x - 172.31.x.x (приватные подсети)

## Дополнительные меры безопасности

### Аутентификация
- Требуется авторизация пользователя
- Проверка сессии для каждого запроса
- Нет доступа для неавторизованных пользователей

### Ограничения времени
- Таймаут 30 секунд на запрос
- Предотвращение зависания сервера
- Автоматическая отмена долгих запросов

### Валидация данных
- Проверка формата URL
- Валидация HTTP методов
- Санитизация заголовков

## Примеры

### ✅ Разрешенные URL
```
https://api.github.com/user
https://httpbin.org/post
https://jsonplaceholder.typicode.com/posts
http://localhost:8080/webhook/test/abc123 (собственный сервер)
```

### ❌ Заблокированные URL
```
http://localhost:3000/admin (внешний localhost)
http://192.168.1.1/router (домашняя сеть)
http://10.0.0.1/internal (корпоративная сеть)
http://172.16.0.1/service (приватная подсеть)
```

## Обход ограничений

Если вам нужно тестировать локальные сервисы:

1. **Используйте тестовые вебхуки dmIntegroff** - они всегда разрешены
2. **Настройте внешний доступ** к вашему локальному сервису
3. **Используйте туннели** (ngrok, localtunnel) для временного доступа
4. **Тестируйте через внешние инструменты** (Postman, curl) напрямую

## Сообщения об ошибках

- `🔒 Запросы к локальным/приватным сетям заблокированы` - попытка доступа к запрещенному адресу
- `🔗 Некорректный формат URL` - неправильный формат адреса
- `🔐 Требуется авторизация` - нет активной сессии пользователя
- `⏱️ Превышено время ожидания` - запрос занял более 30 секунд

## Техническая реализация

Проверка безопасности выполняется в функции `isLocalOrPrivateIP()` с исключением для собственного сервера через `isOwnServer()`. Это обеспечивает баланс между безопасностью и функциональностью.
