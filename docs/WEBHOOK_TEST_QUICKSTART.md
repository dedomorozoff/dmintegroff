# Быстрый старт: Тестирование вебхуков

## Что это?

Функционал тестирования вебхуков позволяет быстро создать временный endpoint для отладки и тестирования интеграций, аналогично популярному сервису webhook.site.

## Как использовать?

### Шаг 1: Создание тестового вебхука

1. Откройте дашборд: `http://localhost:8080/dashboard`
2. Найдите раздел "Быстрые действия"
3. Нажмите кнопку **"Протестировать вебхук"** (с иконкой колбы)
4. URL вебхука автоматически скопируется в буфер обмена
5. Откроется страница с тестовым вебхуком

### Шаг 2: Отправка запросов

Отправьте запрос на полученный URL любым удобным способом:

#### Через curl:
```bash
curl -X POST http://localhost:8080/webhook/test/YOUR_TOKEN \
  -H "Content-Type: application/json" \
  -d '{"test": true, "message": "Hello!"}'
```

#### Через браузер:
Просто откройте URL в браузере (GET запрос):
```
http://localhost:8080/webhook/test/YOUR_TOKEN?param=value
```

#### Через Postman/Insomnia:
1. Создайте новый запрос
2. Вставьте URL вебхука
3. Выберите метод (GET, POST, PUT и т.д.)
4. Добавьте заголовки и тело запроса
5. Отправьте

#### Через кнопку на странице:
На странице тестового вебхука есть кнопка **"Отправить тестовый запрос"**, которая отправит пример запроса.

### Шаг 3: Просмотр результатов

На странице тестового вебхука вы увидите все запросы в реальном времени:

- ✅ HTTP метод и URL
- ✅ Все заголовки запроса
- ✅ Тело запроса (JSON, XML, текст)
- ✅ Query параметры
- ✅ IP адрес отправителя
- ✅ Время получения

Страница автоматически обновляется каждые 5 секунд.

## Примеры использования

### Тестирование webhook от внешнего сервиса

1. Создайте тестовый вебхук
2. Скопируйте URL
3. Вставьте URL в настройки webhook внешнего сервиса (например, GitHub, Stripe, Telegram)
4. Выполните действие, которое должно вызвать webhook
5. Посмотрите, какие данные пришли на страницу тестового вебхука

### Отладка интеграции

1. Создайте тестовый вебхук
2. Используйте его URL как target_api в вашей интеграции
3. Отправьте запрос на вашу интеграцию
4. Посмотрите, что именно отправляется на целевой API

### Проверка формата данных

1. Создайте тестовый вебхук
2. Отправьте на него данные в разных форматах (JSON, XML, form-data)
3. Проверьте, как они отображаются и парсятся

## Ограничения

- ⏱️ Срок действия: 24 часа
- 📊 Хранится: последние 100 запросов
- 🔒 Доступ: только для владельца
- 🔄 Обновление: каждые 2 секунды

## Удаление

Нажмите кнопку **"Удалить"** на странице вебхука. Все данные будут удалены безвозвратно.

## Автоматическое тестирование

Используйте скрипт для автоматической отправки тестовых запросов:

```bash
chmod +x scripts/test_webhook.sh
./scripts/test_webhook.sh
```

Скрипт отправит 5 разных типов запросов и покажет результаты.

## Troubleshooting

### Вебхук не принимает запросы

- Проверьте, не истёк ли срок действия (24 часа)
- Убедитесь, что используете правильный токен в URL
- Проверьте, что сервер запущен и доступен
- Проверьте логи сервера: `tail -f logs/app.log`

### Запросы не отображаются

- Подождите 5 секунд (время обновления)
- Обновите страницу вручную (F5)
- Проверьте консоль браузера на наличие ошибок (F12)
- Убедитесь, что JavaScript не заблокирован

### Ошибка при создании вебхука

- Убедитесь, что вы авторизованы
- Проверьте логи сервера
- Проверьте подключение к базе данных
- Проверьте, что миграция 013 выполнена

### "undefined undefined" в консоли

Это была ошибка в ранней версии, исправлена в последнем обновлении. Обновите страницу (Ctrl+F5) для очистки кэша.

### URL не копируется в буфер обмена

- Убедитесь, что используете HTTPS (для production)
- Проверьте разрешения браузера для clipboard API
- Попробуйте скопировать URL вручную
