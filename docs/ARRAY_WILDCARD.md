# 🔄 Работа с массивами неизвестной длины

## Проблема

Что делать, если в источнике данных массив с неизвестным количеством элементов?

**Входные данные:**
```json
{
  "products": [
    {"title": "Item1", "cost": 100},
    {"title": "Item2", "cost": 200},
    {"title": "Item3", "cost": 300}
  ]
}
```

Раньше нужно было указывать каждый элемент вручную:
```json
{
  "items": [
    {"name": "{{products[0].title}}", "price": {{products[0].cost}}},
    {"name": "{{products[1].title}}", "price": {{products[1].cost}}}
  ]
}
```

Но что если элементов 10? 100? Неизвестно сколько?

## Решение: Wildcard `{{array.*}}`

Используйте специальный синтаксис `{{path.*}}` для копирования **всего массива**:

```json
{
  "items": {{products.*}}
}
```

**Результат:**
```json
{
  "items": [
    {"title": "Item1", "cost": 100},
    {"title": "Item2", "cost": 200},
    {"title": "Item3", "cost": 300}
  ]
}
```

## Примеры использования

### Пример 1: Копирование массива объектов

**Входные данные:**
```json
{
  "orders": [
    {"id": "1", "total": 500, "status": "paid"},
    {"id": "2", "total": 300, "status": "pending"}

  }
```

**Результат:**
```json
{

    {"id": "2", "total": 300, "status": "pending"}
```

```json
}
```

## Синтаксис

### Базовый синтаксис
```
{{path.*}}
```

- `path` - путь к массиву в исходных данных
- `.*` - wildcard, означает "все элементы"

### Примеры путей

| Путь | Описание |
|------|----------|
| `{{items.*}}` | Корневой массив `items` |
| `{{user.orders.*}}` | Вложенный массив `user.orders` |
| `{{data.products.*}}` | Вложенный массив `data.products` |

## Важные замечания

### ✅ Что работает

- Копирование массивов любой длины
- Массивы объектов
- Массивы простых значений (строки, числа)
- Вложенные массивы
- Несколько массивов в одном шаблоне

### ❌ Что НЕ работает

**Трансформация элементов массива:**
```json
// ❌ Не работает - нельзя изменить структуру элементов
{
  "items": {{products.*}} // Копирует как есть
}
```

Если нужно изменить структуру элементов, используйте индексы:
```json
// ✅ Работает - указываем каждый элемент
{
  "items": [
    {"name": "{{products[0].title}}", "price": {{products[0].cost}}},
    {"name": "{{products[1].title}}", "price": {{products[1].cost}}}
  ]
}
```

**Фильтрация элементов:**
```json
// ❌ Не работает - нельзя фильтровать
{
  "activeItems": {{products.*.where(active=true)}}
}
```

**Математические операции:**
```json
// ❌ Не работает - нельзя суммировать
{
  "total": {{sum(products.*.price)}}
}
```

## Комбинирование с другими плейсхолдерами

Можно комбинировать wildcard с обычными плейсхолдерами:

```json
{
  "user": {
    "name": "{{user.name}}",
    "email": "{{user.email}}"
  },
  "orders": {{user.orders.*}},
  "tags": {{tags.*}},
  "metadata": {
    "timestamp": "{{timestamp}}",
    "source": "webhook"
  }
}
```

## Отладка

### Проверка шаблона

Используйте кнопку "Проверить шаблон" для валидации.

### Проверка в логах

После отправки webhook проверьте в разделе "Логи", что было отправлено на Target API.

### Частые ошибки

**Ошибка:** `Failed to process output template`
- **Причина:** Неправильный синтаксис
- **Решение:** Проверьте, что используете `{{path.*}}` без кавычек

**Ошибка:** Массив вставляется как строка
- **Причина:** Забыли `.*` или добавили кавычки
- **Неправильно:** `"{{items.*}}"` или `{{items}}`
- **Правильно:** `{{items.*}}`

## Сравнение методов

| Метод | Когда использовать |
|-------|-------------------|
| `{{items.*}}` | Массив неизвестной длины, копируем как есть |
| `{{items[0].field}}` | Нужен конкретный элемент |
| Ручное перечисление | Нужно изменить структуру элементов |
