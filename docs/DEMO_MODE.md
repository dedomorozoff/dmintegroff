# Демо-режим dmIntegroff

## Описание

Демо-режим позволяет автоматически регистрировать временных пользователей через GET-параметры на странице логина. Это полезно для демонстраций, тестирования и предоставления временного доступа.

## Настройка

Добавьте следующие параметры в файл `.env`:

```env
# Включить демо-режим
DEMO_MODE=true

# Секретный ключ для демо-регистрации
DEMO_SECRET=your-demo-secret-key

# URL для отправки вебхуков в демо-режиме
DEMO_TARGET_URL=https://webhook.site/your-demo-webhook-id
```

## Использование

### Автоматическая регистрация пользователя

Отправьте GET-запрос на страницу логина с параметрами:

```
http://localhost:8080/login?demo_key=your-demo-secret-key&username=demo_user&password=demo_pass
```

Параметры:
- `demo_key` - секретный ключ из `DEMO_SECRET` в `.env`
- `username` - имя пользователя для регистрации
- `password` - пароль пользователя

### Что происходит

1. Система проверяет, что `DEMO_MODE=true` и `demo_key` совпадает с `DEMO_SECRET`
2. Автоматически создается пользователь с указанными логином и паролем
3. Пользователь помечается как демо-пользователь (`is_demo=true`)
4. Устанавливается срок действия 24 часа (`expires_at`)
5. Поля логина и пароля автоматически заполняются на странице
6. Пользователь может войти в систему

### Ограничения для демо-пользователей

1. **Срок действия**: Демо-пользователи автоматически удаляются через 24 часа
2. **Очистка**: Старые демо-пользователи удаляются при каждом заходе на страницу логина
3. **Редактирование Target URL**: Демо-пользователи не могут напрямую редактировать поле Target API URL в настройках интеграций. Поле доступно только для чтения (readonly), но можно использовать кнопку "Тестовый URL" для установки тестового адреса
4. **Вебхуки**: Демо-пользователи могут отправлять вебхуки только на URL, указанный в `DEMO_TARGET_URL`

### Пример использования

1. Настройте `.env`:
```env
DEMO_MODE=true
DEMO_SECRET=my-secret-123
DEMO_TARGET_URL=https://webhook.site/abc-123-def
```

2. Откройте URL:
```
http://localhost:8080/login?demo_key=my-secret-123&username=test_user&password=test123
```

3. Войдите в систему (поля уже заполнены)

4. Создайте интеграцию с `target_api` начинающимся с `https://webhook.site/abc-123-def`

5. Вебхуки будут отправляться только на разрешенный URL

## Безопасность

- Используйте сложный `DEMO_SECRET` для предотвращения несанкционированной регистрации
- Не включайте `DEMO_MODE` в продакшене
- Демо-пользователи имеют роль `specialist` (не `admin`)
- Ограничение на target URL предотвращает отправку вебхуков на произвольные адреса

## Миграция базы данных

Для работы демо-режима необходимо применить миграцию:

**SQLite:**
```bash
sqlite3 dmintegroff.db < migrations/006_add_demo_users_sqlite.sql
```

**MySQL:**
```sql
source migrations/006_add_demo_users.sql
```

Или используйте автоматическую миграцию GORM при запуске приложения.
