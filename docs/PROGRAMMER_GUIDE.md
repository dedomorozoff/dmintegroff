# Руководство программиста GIntegra

Этот документ предназначен для разработчиков, планирующих развивать или модифицировать систему GIntegra.

## 1. Настройка окружения разработки

### Требования
*   **Go**: Версия 1.20 или новее.
*   **Git**: Для управления версиями.
*   **IDE**: Рекомендуется VS Code (с расширением Go) или GoLand.

### Установка зависимостей
Проект использует Go Modules. Для загрузки всех зависимостей выполните:
```bash
go mod tidy
```

## 2. Структура проекта и соглашения

Мы придерживаемся стандартной структуры Go-проектов:

*   **`cmd/server/main.go`**: Точка входа. Здесь инициализируется БД и запускается веб-сервер.
*   **`internal/`**: Внутренний код приложения.
    *   **`models/`**: GORM-модели. Каждая модель в отдельном файле.
    *   **`controllers/`**: Логика обработки HTTP-запросов. Группируются по функционалу (auth, integration).
    *   **`routes/`**: Регистрация маршрутов и middleware.
    *   **`services/`**: Бизнес-логика, не привязанная к HTTP (например, обработка вебхуков).
    *   **`database/`**: Управление подключением к БД.

## 3. Расширение функционала

### Добавление новой сущности (Модели)
1.  Создайте файл в `internal/models/` (например, `log.go`).
2.  Определите структуру с тегами GORM и JSON.
3.  Добавьте модель в функцию `Migrate` в `cmd/server/main.go` (или `internal/database/db.go`), чтобы таблица создалась автоматически.

### Добавление нового контроллера
1.  Создайте файл в `internal/controllers/`.
2.  Реализуйте функции-обработчики: `func MyHandler(c *gin.Context)`.
3.  Используйте `c.HTML` для рендеринга шаблонов или `c.JSON` для API ответов.

### Регистрация маршрута
1.  Откройте `internal/routes/routes.go`.
2.  Добавьте новый маршрут в `SetupRouter`.
    *   Для публичных маршрутов: `r.GET("/path", controllers.MyHandler)`.
    *   Для защищенных маршрутов (требующих вход): добавьте внутрь группы `authorized`.

## 4. Работа с базой данных

Мы используем **GORM**.
*   **Миграции**: Выполняются автоматически при старте (`AutoMigrate`). При изменении структуры моделей GORM попытается обновить схему БД.
*   **Запросы**: Используйте глобальный объект `database.DB`.
    ```go
    var users []models.User
    result := database.DB.Where("role = ?", "admin").Find(&users)
    ```

## 5. Сборка для продакшена

Для компиляции исполняемого файла выполните:

**Windows:**
```bash
go build -o gintegra.exe cmd/server/main.go
```

**Linux/macOS:**
```bash
go build -o gintegra cmd/server/main.go
```

Убедитесь, что папка `templates/` находится рядом с исполняемым файлом при запуске.
