# Пример использования демо-режима

## Быстрый старт

### 1. Настройка демо-режима

Отредактируйте `.env`:

```env
DEMO_MODE=true
DEMO_SECRET=demo123
DEMO_TARGET_URL=https://webhook.site/abc-123-def
```

### 2. Создание демо-пользователя

Откройте в браузере:

```
http://localhost:8080/login?demo_key=demo123&username=test_user&password=test123
```

Вы увидите:
- ✅ Сообщение "Демо-пользователь автоматически зарегистрирован"
- Поля логина и пароля уже заполнены
- Нажмите "Войти в систему"

### 3. Создание интеграции

После входа:

1. Перейдите в "Интеграции" → "Создать интеграцию"
2. Заполните форму:
   - **Название**: Тестовая интеграция
   - **Проект**: Выберите существующий или создайте новый
   - **Target API**: `https://webhook.site/abc-123-def` (должен начинаться с DEMO_TARGET_URL)
3. Сохраните интеграцию

### 4. Отправка тестового вебхука

Скопируйте Webhook URL из интеграции и отправьте POST-запрос:

```bash
curl -X POST http://localhost:8080/webhook/YOUR_TOKEN \
  -H "Content-Type: application/json" \
  -d '{"test": "data", "user": "demo"}'
```

### 5. Настройка маппинга

1. Интеграция перейдет в режим "listening" и захватит данные
2. Перейдите в "Настроить маппинг"
3. Настройте поля и сохраните
4. Интеграция станет активной

### 6. Проверка ограничений

Попробуйте изменить Target API на другой URL (например, `https://example.com`):

```bash
# Это НЕ сработает для демо-пользователя
curl -X POST http://localhost:8080/webhook/YOUR_TOKEN \
  -H "Content-Type: application/json" \
  -d '{"test": "data"}'
```

Вы получите ошибку: "demo users can only send webhooks to demo target URL"

## Автоматическая очистка

Демо-пользователи автоматически удаляются:
- Через 24 часа после создания
- При заходе любого пользователя на страницу логина (очистка истекших)

## Проверка демо-пользователей

Вы можете проверить список демо-пользователей в базе данных:

```bash
# SQLite
sqlite3 dmintegroff.db "SELECT username, is_demo, expires_at FROM users WHERE is_demo = 1;"

# MySQL
mysql -u user -p -e "SELECT username, is_demo, expires_at FROM users WHERE is_demo = 1;" database_name
```

## Отключение демо-режима

Установите в `.env`:

```env
DEMO_MODE=false
```

После этого:
- GET-параметры на странице логина будут игнорироваться
- Существующие демо-пользователи продолжат работать до истечения срока
- Ограничения на Target API будут сняты для всех пользователей
