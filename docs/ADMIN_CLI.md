# Администрирование GIntegra через CLI

Для управления приложением из консоли используйте утилиту `admin`.

## Запуск

```bash
go run cmd/admin/main.go
```

## Доступные команды

### Интерактивный режим
Просто запустите без параметров для отображения меню:
```bash
go run cmd/admin/main.go
```

### Сброс пароля администратора
```bash
go run cmd/admin/main.go -reset-password
```

Или выберите пункт 1 в интерактивном меню.

### Генерация случайного URL
```bash
go run cmd/admin/main.go -generate-secret
```

Или выберите пункт 2 в интерактивном меню.

Эта команда сгенерирует случайный путь для приложения (например, `/a3f9c2e1b4d8f7a6`).

**Как использовать:**
1. Скопируйте сгенерированный путь
2. Добавьте в `.env` файл:
   ```
   APP_PATH=/a3f9c2e1b4d8f7a6
   ```
3. Перезапустите сервер
4. Теперь приложение доступно по адресу `http://localhost:8080/a3f9c2e1b4d8f7a6`

**Зачем это нужно?**
- Скрывает приложение от сканеров и ботов
- Добавляет дополнительный уровень безопасности
- Полезно для внутренних инструментов

## Компиляция утилиты

Для удобства можно скомпилировать утилиту:

```bash
go build -o gintegra-admin.exe cmd/admin/main.go
```

Затем запускать:
```bash
./gintegra-admin.exe
```
