# 📋 Roadmap Summary

Краткий обзор планируемых функций dmIntegroff.

---

## 🔥 Высокий приоритет (Ближайшие релизы)

### 1. Использование запроса в качестве образца данных в тестовом хуке
**Статус:** 📋 Запланировано  
**Релиз:** v1.x+1.x

Возможность использовать полученный запрос в тестовом webhook как образец данных для настройки маппинга интеграции.

**Польза:**
- Упрощение тестирования
- Быстрое создание маппинга
- Удобство при разработке

---

### 2. Поддержка различных форматов входящих данных
**Статус:** 📋 Запланировано  
**Релиз:** v1.x+2.x

Расширение возможностей приема данных: form-data, XML, plain text, binary.

**Польза:**
- Универсальность системы
- Поддержка legacy систем
- Интеграция с большим количеством источников

---

### 3. Тестирование запроса после настройки маппинга
**Статус:** 📋 Запланировано  
**Релиз:** v1.x+1.x

Кнопка "Протестировать запрос" для проверки маппинга без активации интеграции.

**Польза:**
- Быстрая проверка маппинга
- Отладка трансформаций
- Уверенность перед активацией

---

### 4. Множественные маппинги на один webhook
**Статус:** 📋 Запланировано  
**Релиз:** v2.0.0 (Мажорный релиз)

Один webhook → несколько Target API с разными маппингами.

**Польза:**
- Упрощение архитектуры
- Централизованное управление
- Экономия ресурсов

**Пример:**
```
Webhook: новый заказ
├─ Выход 1: CRM (Salesforce)
├─ Выход 2: Analytics (Google Analytics)
├─ Выход 3: Email (SendGrid)
└─ Выход 4: Warehouse (внутренняя система)
```

**Документация:** [Детальный дизайн](MULTIPLE_OUTPUTS_DESIGN.md)

---

### 5. Исправление бага в редакторе образца данных
**Статус:** 📋 Запланировано  
**Релиз:** v1.x.x (Ближайший)

Исправление проблем с редактированием образца данных без предварительного получения webhook.

**Проблемы:**
- Редактор не инициализируется для пустого payload
- Валидация JSON не работает
- Подсветка синтаксиса глючит

---

## 💡 Средний приоритет (Будущие релизы)

- **Визуальный редактор маппинга** - drag-and-drop интерфейс
- **Webhook очереди** - буферизация при недоступности Target API
- **Webhook replay** - повторная отправка запросов
- **Статистика и аналитика** - детальная статистика по интеграциям

---

## 💤 Низкий приоритет (Идеи для обсуждения)

- **Webhook фильтры** - условия для обработки запросов
- **API для управления** - REST API для программного управления
- **Webhook templates** - библиотека готовых шаблонов
- **Multi-tenancy** - поддержка множественных организаций
- **Webhook chains** - цепочки обработки
- **Data transformation functions** - встроенные функции трансформации
- **Webhook scheduling** - отложенная отправка
- **Rate limiting** - ограничение частоты запросов
- **Circuit breaker** - автоматическое отключение при ошибках
