# Полуавтоматическая интеграция - Руководство

## Как это работает

GIntegra теперь поддерживает полуавтоматическую настройку интеграций через режим прослушивания.

### Шаг 1: Создание интеграции

1. Перейдите в "Интеграции" → "Создать новую"
2. Укажите:
   - **Название** - описательное имя интеграции
   - **Target API URL** - куда будут отправляться данные
   - **Source API** (опционально) - для документации

3. Нажмите "Создать интеграцию"

### Шаг 2: Получение webhook URL

После создания интеграция автоматически переходит в режим **"Прослушивание"** 🎧

В списке интеграций вы увидите:
- Уникальный webhook URL (например: `/webhook/a3f9c2e1b4d8f7a6`)
- Кнопку 📋 для копирования полного URL

### Шаг 3: Отправка тестового запроса

Настройте источник данных отправлять webhook на полученный URL:
```
POST http://localhost:8080/webhook/a3f9c2e1b4d8f7a6
Content-Type: application/json

{
  "user_id": 123,
  "email": "test@example.com",
  "order_total": 99.99
}
```

Система сохранит структуру первого запроса как образец.

### Шаг 4: Настройка маппинга полей

1. В списке интеграций нажмите "Настроить"
2. Вы увидите:
   - Полученные данные (образец)
   - Таблицу для маппинга полей

3. Для каждого поля укажите:
   - **Новое имя** - как поле должно называться в Target API
   - **Игнорировать** - если поле не нужно передавать

Пример:
| Поле из источника | Новое имя для Target API |
|-------------------|--------------------------|
| user_id           | customer_id              |
| email             | email                    |
| order_total       | amount                   |

4. Нажмите "Сохранить и активировать"

### Шаг 5: Интеграция активна ✅

Интеграция переходит в режим **"Активна"**.

Теперь все входящие запросы будут:
1. Приниматься на webhook URL
2. Преобразовываться согласно маппингу
3. Отправляться на Target API

## Режимы интеграции

- 🎧 **Прослушивание** - ожидает первый запрос для определения структуры
- ✅ **Активна** - обрабатывает и перенаправляет запросы
- ⏸️ **Неактивна** - интеграция отключена

## Пример полного цикла

```bash
# 1. Создайте интеграцию через UI
# Target API: https://api.example.com/orders

# 2. Скопируйте webhook URL: /webhook/abc123

# 3. Отправьте тестовый запрос
curl -X POST http://localhost:8080/webhook/abc123 \
  -H "Content-Type: application/json" \
  -d '{"order_id": 1, "customer": "John", "total": 100}'

# 4. Настройте маппинг через UI:
# order_id -> id
# customer -> customer_name
# total -> amount

# 5. Активируйте интеграцию

# 6. Теперь все запросы будут преобразовываться и отправляться на Target API
```

## Безопасность

- Каждая интеграция имеет уникальный токен в URL
- Токен генерируется криптографически стойким генератором
- Невозможно угадать URL другой интеграции
