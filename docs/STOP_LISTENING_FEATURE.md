# 🛑 Остановка ожидания данных

Документация по функции остановки ожидания данных с сохранением возможности настройки маппинга.

---

## 📋 Обзор

Функция позволяет остановить автоматическое ожидание webhook данных, сохраняя при этом возможность вручную настроить маппинг полей и активировать интеграцию.

### Проблема, которую решает

**До:**
- При остановке ожидания интеграция деактивировалась
- Пользователь перенаправлялся на список интеграций
- Терялся контекст настройки
- Нужно было заново открывать страницу настройки маппинга

**После:**
- Остановка ожидания не закрывает страницу настройки
- Можно продолжить настройку маппинга вручную
- Сохраняется контекст работы
- Интеграция переходит в режим `inactive` (доступна для настройки)

---

## 🎯 Использование

### Сценарий 1: Остановка ожидания на странице настройки маппинга

1. Создайте интеграцию (она автоматически переходит в режим `listening`)
2. Откройте страницу настройки маппинга: `/integrations/:id/configure`
3. Вы увидите синий индикатор "Ожидание данных..."
4. Нажмите кнопку **"Остановить ожидание"** (в индикаторе или внизу формы)
5. Подтвердите действие
6. ✅ Страница остается открытой, появляется серый индикатор "Ожидание остановлено"
7. Настройте маппинг вручную (если есть полученные данные)
8. Нажмите **"Сохранить и активировать"**

### Сценарий 2: Остановка ожидания из списка интеграций

1. Откройте список интеграций: `/integrations`
2. Найдите интеграцию в режиме `listening`
3. Откройте меню действий (три точки)
4. Нажмите **"Отменить прослушивание"**
5. Подтвердите действие
6. ✅ Интеграция переходит в режим `inactive`
7. Можно открыть настройку маппинга и продолжить настройку

### Сценарий 3: Ручная настройка после остановки

1. Интеграция в режиме `inactive` (ожидание остановлено)
2. Откройте страницу настройки маппинга
3. Вы увидите серый индикатор "Ожидание остановлено"
4. Если есть полученные данные - настройте маппинг
5. Если данных нет - можно вручную ввести образец JSON
6. Нажмите **"Сохранить и активировать"**
7. ✅ Интеграция переходит в режим `active` и начинает работать

## 🔧 Технические детали

### Backend

**Функция:** `IntegrationCancelListening`
**Файл:** `internal/controllers/integration_controller.go`

```go
func IntegrationCancelListening(c *gin.Context) {
    // ... получение интеграции ...
    
    // Переводим в режим неактивна
    integration.Mode = "inactive"
    database.DB.Save(&integration)
    
    // Проверяем, откуда пришел запрос
    redirectTo := c.Query("redirect")
    if redirectTo == "configure" {
        // Возвращаемся на страницу настройки маппинга
        c.Redirect(http.StatusFound, fmt.Sprintf("/integrations/%d/configure", id))
    } else {
        // Иначе на список интеграций
        c.Redirect(http.StatusFound, "/integrations")
    }
}
```

## 🔄 Состояния интеграции

### Диаграмма переходов

```
┌─────────────┐
│  listening  │ ◄─── Создание интеграции
└──────┬──────┘      Переопределение маппинга
       │
       ├─────► [Получен webhook] ──► Настройка маппинга ──► active
       │
       └─────► [Остановить ожидание] ──► inactive
                                           │
                                           └──► [Настроить и активировать] ──► active

┌─────────────┐
│   active    │ ◄─── Интеграция работает
└──────┬──────┘
       │
       ├─────► [Деактивировать] ──► inactive
       │
       └─────► [Переопределить маппинг] ──► listening
```

### Описание режимов

| Режим | Описание | Действия |
|-------|----------|----------|
| `listening` | Ожидает webhook для захвата структуры данных | Остановить ожидание, Настроить маппинг (если данные получены) |
| `inactive` | Неактивна, доступна для настройки | Настроить маппинг, Активировать, Переопределить маппинг |
| `active` | Работает, обрабатывает webhook | Деактивировать, Редактировать маппинг, Переопределить маппинг |

```bash
# 6. Активировать
```

## ⚠️ Важные замечания

1. **Сохранение данных:** При остановке ожидания полученные данные (`SamplePayload`) сохраняются
2. **Режим inactive:** Интеграция не обрабатывает webhook в этом режиме
3. **Ручная настройка:** Можно настроить маппинг даже без полученных данных
4. **Активация:** После настройки нужно нажать "Сохранить и активировать"
5. **Переопределение:** Для активной интеграции есть кнопка "Переопределить маппинг"
