# Схема работы демо-режима

## Процесс регистрации

```
┌─────────────────────────────────────────────────────────────┐
│ Пользователь открывает URL с параметрами │
│ /login?demo_key=SECRET&username=demo&password=pass │
└────────────────────────┬────────────────────────────────────┘
 │
 ▼
┌─────────────────────────────────────────────────────────────┐
│ LoginPage() контроллер │
│ 1. Проверяет DEMO_MODE=true │
│ 2. Сравнивает demo_key с DEMO_SECRET │
│ 3. Извлекает username и password │
└────────────────────────┬────────────────────────────────────┘
 │
 ▼
┌─────────────────────────────────────────────────────────────┐
│ RegisterDemoUser() │
│ 1. Проверяет существование пользователя │
│ 2. Если существует - обновляет expires_at │
│ 3. Если нет - создает нового │
│ - is_demo = true │
│ - expires_at = now + 24h │
│ - role = specialist │
└────────────────────────┬────────────────────────────────────┘
 │
 ▼
┌─────────────────────────────────────────────────────────────┐
│ Страница логина │
│ - Показывает уведомление об успешной регистрации │
│ - Автоматически заполняет поля username и password │
│ - Пользователь нажимает "Войти" │
└─────────────────────────────────────────────────────────────┘
```

## Процесс отправки вебхука

```
┌─────────────────────────────────────────────────────────────┐
│ Входящий вебхук │
│ POST /webhook/{token} │
└────────────────────────┬────────────────────────────────────┘
 │
 ▼
┌─────────────────────────────────────────────────────────────┐
│ WebhookHandler() │
│ 1. Находит интеграцию по токену │
│ 2. Логирует входящий запрос │
│ 3. Вызывает ProcessWebhook() │
└────────────────────────┬────────────────────────────────────┘
 │
 ▼
┌─────────────────────────────────────────────────────────────┐
│ ProcessWebhook() │
│ 1. Загружает интеграцию с пользователем (Preload) │
│ 2. Вызывает ValidateDemoMode() │
└────────────────────────┬────────────────────────────────────┘
 │
 ▼
┌─────────────────────────────────────────────────────────────┐
│ ValidateDemoMode() │
│ 1. Проверяет DEMO_MODE=true │
│ 2. Проверяет user.IsDemo │
│ 3. Если демо-пользователь: │
│ - Проверяет, что target_api начинается с │
│ DEMO_TARGET_URL │
│ - Если нет - возвращает ошибку │
└────────────────────────┬────────────────────────────────────┘
 │
 ▼
┌─────────────────────────────────────────────────────────────┐
│ Отправка на target API │
│ - Если валидация прошла - отправляет вебхук │
│ - Логирует результат │
└─────────────────────────────────────────────────────────────┘
```

## Процесс очистки

```
┌─────────────────────────────────────────────────────────────┐
│ Любой пользователь заходит на /login │
└────────────────────────┬────────────────────────────────────┘
 │
 ▼
┌─────────────────────────────────────────────────────────────┐
│ LoginPage() │
│ Вызывает CleanupExpiredDemoUsers() │
└────────────────────────┬────────────────────────────────────┘
 │
 ▼
┌─────────────────────────────────────────────────────────────┐
│ CleanupExpiredDemoUsers() │
│ DELETE FROM users │
│ WHERE is_demo = true AND expires_at < NOW() │
└─────────────────────────────────────────────────────────────┘
```

## Жизненный цикл демо-пользователя

```
Создание Использование Удаление
 │ │ │
 ▼ ▼ ▼
┌──────┐ ┌──────────┐ ┌──────────┐
│ GET │────────────────▶│ Работа │───────────▶│ Очистка │
│ /login│ │ 24 часа │ │ при входе│
│ ?demo │ │ │ │ на /login│
└──────┘ └──────────┘ └──────────┘
 │ │ │
 │ │ │
 ▼ ▼ ▼
is_demo=true Создание is_demo=true
expires_at= интеграций expires_at < now
now+24h Отправка DELETE
role=specialist вебхуков
```

## Проверки безопасности

```
┌─────────────────────────────────────────────────────────────┐
│ Регистрация │
│ DEMO_MODE должен быть true │
│ demo_key должен совпадать с DEMO_SECRET │
│ username и password обязательны │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ Отправка вебхуков │
│ Проверка user.IsDemo │
│ target_api должен начинаться с DEMO_TARGET_URL │
│ Роль всегда specialist (не admin) │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ Очистка │
│ Автоматическая при заходе на /login │
│ Удаление только истекших (expires_at < now) │
│ Индекс на expires_at для быстрой очистки │
└─────────────────────────────────────────────────────────────┘
```

## Конфигурация

```
.env файл
├── DEMO_MODE=true/false # Включить/выключить
├── DEMO_SECRET=key # Секретный ключ
└── DEMO_TARGET_URL=https://... # Разрешенный URL

База данных (users)
├── is_demo (BOOLEAN) # Флаг демо-пользователя
├── expires_at (DATETIME) # Время истечения
└── INDEX(expires_at) # Индекс для очистки
```

## Примеры использования

### Успешная регистрация
```
URL: /login?demo_key=secret123&username=test&password=pass123
 ↓
Проверка: demo_key == DEMO_SECRET 
 ↓
Создание: User{username: test, is_demo: true, expires_at: now+24h}
 ↓
Результат: Автозаполненная форма логина + уведомление
```

### Неудачная регистрация
```
URL: /login?demo_key=wrong&username=test&password=pass123
 ↓
Проверка: demo_key == DEMO_SECRET ✗
 ↓
Результат: Обычная форма логина (без автозаполнения)
```

### Успешная отправка вебхука
```
Integration: target_api = https://webhook.site/abc-123
User: is_demo = true
Config: DEMO_TARGET_URL = https://webhook.site/
 ↓
Проверка: target_api.startsWith(DEMO_TARGET_URL) 
 ↓
Результат: Вебхук отправлен
```

### Неудачная отправка вебхука
```
Integration: target_api = https://example.com/webhook
User: is_demo = true
Config: DEMO_TARGET_URL = https://webhook.site/
 ↓
Проверка: target_api.startsWith(DEMO_TARGET_URL) ✗
 ↓
Результат: Ошибка "demo users can only send webhooks to demo target URL"
```
