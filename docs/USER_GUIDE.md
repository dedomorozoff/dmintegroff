## Введение

dmIntegroff — это система для управления интеграциями между различными REST API. Она позволяет:
- Принимать данные через webhook
- Трансформировать их согласно настроенному маппингу
- Отправлять на целевой API
- Отслеживать все операции в логах

## Первый вход

1. Откройте браузер и перейдите по адресу: `http://localhost:8080`
2. Введите учетные данные по умолчанию:
   - **Логин**: `admin`
   - **Пароль**: `admin`
3. После входа рекомендуется сменить пароль в настройках

⚠️ **Важно**: Обязательно смените пароль администратора после первого входа!

## Панель управления

После входа вы попадаете на главную страницу (Обзор), где отображается:

### Статистика
- **Всего интеграций** - общее количество созданных интеграций
- **Активных** - количество работающих интеграций
- **В режиме ожидания** - интеграции, требующие настройки
- **Обработано** - общее количество обработанных webhook запросов (кликните для просмотра графика)

### Быстрые действия
- Создать проект
- Все проекты
- Интеграции
- Просмотр логов

### Прогресс для новых пользователей
Система показывает шаги для начала работы:
1. ✓ Создайте проект для группировки интеграций
2. ✓ Создайте интеграцию в проекте
3. ✓ Отправьте тестовый запрос на webhook URL
4. ✓ Настройте маппинг полей
5. ✓ Активируйте интеграцию

### Последняя активность
Отображает последние 10 операций с интеграциями:
- Статус операции (успех/ошибка/предупреждение)
- Название интеграции
- Описание операции
- Время выполнения

Обновляется автоматически каждые 30 секунд.

## Работа с проектами

Проекты помогают организовать интеграции по группам (например, по клиентам или системам).

### Создание проекта

1. Перейдите в раздел **"Проекты"** → **"Создать проект"**
2. Заполните форму:
   - **Название** - имя проекта (обязательно)
   - **Описание** - краткое описание (опционально)
3. Нажмите **"Создать"**

### Управление проектом

В карточке проекта доступны действия:
- **Просмотр** - список всех интеграций проекта
- **Редактировать** - изменение названия и описания
- **Удалить** - удаление проекта (⚠️ все интеграции проекта также будут удалены)

## Создание интеграций

### Шаг 1: Создание

1. Перейдите в **"Интеграции"** → **"Создать"**
2. Заполните форму:
   - **Название** - имя интеграции
   - **Проект** - выберите проект (обязательно)
   - **Source API** - URL источника данных (опционально)
   - **Target API** - URL целевого API (обязательно)
3. Нажмите **"Создать"**

После создания интеграция переходит в режим **"Прослушивание"** и получает уникальный webhook URL.

### Шаг 2: Захват структуры данных

Отправьте тестовый запрос на webhook URL:

```bash
curl -X POST http://localhost:8080/webhook/YOUR_TOKEN \
  -H "Content-Type: application/json" \
  -d '{
    "user": {
      "name": "John Doe",
      "email": "john@example.com"
    },
    "order_id": 12345
  }'
```

Система автоматически захватит структуру данных и предложит настроить маппинг.

### Шаг 3: Настройка маппинга

1. Нажмите **"Настроить маппинг"** на карточке интеграции
2. Вы увидите:
   - Исходные данные (Sample Payload)
   - Список всех полей, включая вложенные
3. Настройте маппинг:
   - В поле **"Целевое поле"** укажите имя поля в Target API
   - В поле **"Исходное поле"** выберите путь к данным из источника
4. Нажмите **"Сохранить маппинг"**

Интеграция автоматически активируется.

### Пример маппинга

**Исходные данные:**
```json
{
  "user": {
    "name": "John Doe",
    "email": "john@example.com"
  },
  "order_id": 12345
}
```

**Маппинг:**
- `customer_name` ← `user.name`
- `customer_email` ← `user.email`
- `order_number` ← `order_id`

**Результат на Target API:**
```json
{
  "customer_name": "John Doe",
  "customer_email": "john@example.com",
  "order_number": 12345
}
```

## Настройка маппинга

### Поддержка вложенных полей

Система поддерживает работу с вложенными объектами:
- `user.name` - доступ к полю name внутри объекта user
- `address.city` - доступ к полю city внутри объекта address
- `items[0].price` - доступ к первому элементу массива

### Редактирование маппинга

Для изменения маппинга активной интеграции:
1. Нажмите **"Переопределить маппинг"**
2. Интеграция перейдет в режим прослушивания
3. Отправьте новый тестовый запрос
4. Настройте маппинг заново

### Редактирование JSON вручную

Вы можете редактировать Sample Payload напрямую:
1. В форме настройки маппинга найдите поле с JSON
2. Отредактируйте структуру данных
3. Нажмите **"Обновить поля"**
4. Настройте маппинг для новых полей

## Мониторинг и логи

### Просмотр логов

Раздел **"Тесты интеграций"** показывает все запросы:
- Тип запроса (webhook/test/error)
- Статус выполнения
- Время запроса
- Детали запроса и ответа

### Фильтрация

Доступны фильтры:
- По проекту
- По интеграции
- По статусу (успех/ошибка)
- Поиск по ID или названию

### Детали запроса

Кликните на запись лога для просмотра:
- HTTP метод и URL
- Заголовки запроса (с подсветкой JSON)
- Тело запроса
- Тело ответа
- Код статуса
- Сообщение об ошибке (если есть)

### Очистка логов

Система автоматически хранит только последние 50 записей. Для ручной очистки:
1. Перейдите в **"Тесты интеграций"**
2. Нажмите **"Очистить все логи"**

## Настройки пользователя

### Смена пароля

1. Перейдите в **"Настройки"** (иконка шестеренки в боковом меню)
2. В разделе **"Смена пароля"** заполните:
   - **Текущий пароль** - для подтверждения
   - **Новый пароль** - минимум 6 символов
   - **Подтверждение пароля** - повторите новый пароль
3. Нажмите **"Изменить пароль"**

### Требования к паролю

- Минимум 6 символов
- Пароли должны совпадать
- Требуется знание текущего пароля

## Статистика

### График запросов

Для просмотра статистики за последние 30 дней:
1. На главной странице кликните на блок **"Обработано"**
2. Откроется модальное окно с графиком
3. График показывает количество обработанных webhook запросов по дням

### Интерпретация данных

- **Ось X** - даты (последние 30 дней)
- **Ось Y** - количество запросов
- **Точки на графике** - данные за конкретный день
- **Наведение курсора** - подробная информация

### Закрытие графика

- Кликните на крестик в правом верхнем углу
- Или кликните вне модального окна

## Советы и рекомендации

### Организация работы

1. **Используйте проекты** для группировки связанных интеграций
2. **Давайте понятные имена** интеграциям и проектам
3. **Тестируйте маппинг** перед активацией интеграции
4. **Проверяйте логи** регулярно для выявления проблем

### Отладка

1. **Используйте тестовый endpoint** `/webhook/test` для проверки структуры данных
2. **Проверяйте логи** для понимания, что пошло не так
3. **Переопределяйте маппинг** если структура данных изменилась
4. **Деактивируйте интеграцию** на время отладки

### Безопасность

1. **Смените пароль** администратора после установки
2. **Используйте сложные пароли** (минимум 8 символов, буквы и цифры)
3. **Не делитесь webhook токенами** публично
4. **Регулярно проверяйте логи** на подозрительную активность

## Часто задаваемые вопросы

**Q: Как удалить интеграцию?**  
A: Откройте карточку интеграции и нажмите кнопку "Удалить".

**Q: Можно ли изменить webhook токен?**  
A: Да, в настройках интеграции есть кнопка "Регенерировать токен".

**Q: Что делать, если интеграция не работает?**  
A: Проверьте логи, убедитесь что Target API доступен, проверьте маппинг полей.

**Q: Как посмотреть, какие данные отправляются на Target API?**  
A: В логах есть поле "Response Body" с данными, которые были отправлены.

**Q: Можно ли использовать одну интеграцию для разных источников?**  
A: Да, webhook URL можно использовать из любого источника, главное чтобы структура данных совпадала.
