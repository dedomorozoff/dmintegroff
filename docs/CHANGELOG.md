# 📝 Changelog

Все значимые изменения в проекте dmIntegroff документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

- 🔍 История запросов с фильтрацией и поиском

- 📤 Экспорт данных в CSV/JSON

## [1.5.0] - 2024-12-09

### Добавлено
- ✨ **Множественные выходы** - один webhook может отправлять данные на несколько Target API
- 🎯 Управление выходами через отдельный интерфейс
- 🔄 Параллельная обработка выходов через goroutines
- 🎛️ Независимая настройка аутентификации для каждого выхода
- 📊 Условное выполнение выходов (UI готов, логика в разработке)

### Улучшено
- 🚀 Производительность обработки webhook за счет параллелизма
- 🛡️ Надежность - ошибка в одном выходе не влияет на другие
- 📝 Логирование операций с выходами

## [1.4.0] - 2024-12-08

### Добавлено
- 📄 **Поддержка множественных форматов данных**:
  - JSON (как раньше)
  - XML (application/xml, text/xml)
  - Form-data (application/x-www-form-urlencoded, multipart/form-data)
  - Plain text
- 🔄 Автоматическое определение формата по Content-Type
- 🎨 Редактор образца данных с выбором формата
- ✅ Валидация для каждого типа формата

### Добавлено
- 🧪 **Тестирование маппинга** - кнопка "Протестировать запрос" в настройках
- 📋 Использование запроса как образца данных в тестовом webhook
- 🔧 Модальные окна для выбора интеграции и просмотра результатов

### Исправлено
- 🐛 Баги в редакторе образца данных
- 🎯 Улучшена подсветка синтаксиса JSON
- ✨ Упрощена обработка paste событий

## [1.3.0] - 2024-11-25

### Добавлено
- 🔐 **OAuth 2.0 поддержка** для Target API
- 🔑 Bearer Token и Basic Auth аутентификация
- 🔄 Автоматическое обновление OAuth токенов
- 🧪 Тестирование подключения к Target API

### Добавлено
- 📊 **GraphQL интеграции**:
  - Отправка queries и mutations
  - Schema introspection
  - Маппинг переменных
  - Поддержка плейсхолдеров {{field.path}}

### Улучшено
- 🎨 Интерфейс настройки аутентификации
- 📝 Документация по OAuth и GraphQL

## [1.2.0] - 2024-11-15

### Добавлено
- 📁 **Проекты** - группировка интеграций
- 📤 **Экспорт/импорт** конфигураций
- 📊 **Расширенная аналитика** с графиками
- 🔍 **Webhook тестирование** - встроенный endpoint для отладки

### Улучшено
- 🎨 Современный UI с темной темой
- 📱 Мобильная адаптация
- ⚡ Производительность загрузки страниц

## [1.1.0] - 2024-10-30

### Добавлено
- 🎨 **Подсветка синтаксиса JSON** в редакторах
- 🔧 **Кастомные JSON шаблоны** с плейсхолдерами {{field.path}}
- 🌟 **Wildcard для массивов** {{array.*}}
- ✅ **Валидация JSON** с детальными сообщениями об ошибках

### Улучшено
- 🎯 UX редактирования маппингов
- 📝 Автоформатирование JSON
- 🔍 Быстрое копирование плейсхолдеров

## [1.0.0] - 2024-10-01

### Добавлено
- 🚀 **Базовая функциональность интеграций**:
  - Создание и управление интеграциями
  - Webhook endpoints для приема данных
  - Простое маппинг полей
  - Отправка на Target API
- 👤 **Система аутентификации**:
  - Регистрация и вход пользователей
  - Ролевая модель (Администратор/Специалист)
  - Безопасное хранение паролей
- 📊 **Базовая аналитика**:
  - Счетчики запросов
  - Статистика интеграций
  - Логирование операций
- 🎨 **Веб-интерфейс**:
  - Адаптивный дизайн
  - Русский интерфейс
  - Интуитивная навигация

### Техническое
- 🏗️ Архитектура на Go с Gin framework
- 🗄️ GORM для работы с базой данных
- 🎨 Server-side рендеринг с Go templates
- 📝 Структурированное логирование
- 🔒 Session-based аутентификация
