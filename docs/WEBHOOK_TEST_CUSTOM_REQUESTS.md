# Кастомные запросы в тестовых вебхуках

## Обзор

В дополнение к стандартной кнопке "Тестовый запрос", которая отправляет предустановленный JSON запрос на тестовый вебхук, теперь доступна возможность отправки кастомных HTTP запросов **на любой URL** с полным контролем над всеми параметрами.

## Новая функциональность

### Кнопка "Кастомный запрос"

На странице тестового вебхука теперь есть две кнопки:

1. **"Тестовый запрос"** - отправляет предустановленный JSON запрос (как раньше)
2. **"Кастомный запрос"** - открывает модальное окно для настройки запроса

### Возможности кастомного запроса

#### URL назначения
- **Любой URL** - отправка на внешние API, сервисы, локальные серверы
- **Быстрые кнопки**:
  - "Текущий вебхук" - URL тестового вебхука
  - "HTTPBin" - https://httpbin.org/post (для тестирования)
  - "JSONPlaceholder" - https://jsonplaceholder.typicode.com/posts
  - "Postman Echo" - https://postman-echo.com/post
- **Валидация URL** - проверка корректности введенного адреса

#### HTTP Методы
- GET
- POST (по умолчанию)
- PUT
- PATCH
- DELETE
- HEAD
- OPTIONS

#### Настройка заголовков
- Добавление произвольных заголовков
- По умолчанию добавлены:
  - `Content-Type: application/json`
  - `User-Agent: DmIntegroff`
- Возможность добавить/удалить заголовки динамически
- Кнопка "+" для добавления новых заголовков
- Кнопка "×" для удаления заголовков

#### Query параметры
- Добавление произвольных query параметров
- Динамическое добавление/удаление параметров
- Автоматическое формирование URL с параметрами

#### Тело запроса
- Произвольный текст
- Шаблоны для быстрого заполнения:
  - **JSON** - структурированный JSON объект
  - **XML** - XML документ
  - **Form Data** - URL-encoded данные
  - **Text** - простой текст
- Кнопка "Очистить" для очистки поля

## Использование

### Шаг 1: Открытие модального окна
1. Перейдите на страницу тестового вебхука
2. Нажмите кнопку **"Кастомный запрос"**

### Шаг 2: Настройка запроса
1. **Укажите URL назначения**:
   - Введите любой URL вручную
   - Или используйте быстрые кнопки для популярных сервисов
   - По умолчанию подставляется URL текущего тестового вебхука
2. **Выберите HTTP метод** из выпадающего списка
3. **Настройте заголовки**:
   - Измените существующие заголовки
   - Добавьте новые с помощью кнопки "+"
   - Удалите ненужные с помощью кнопки "×"
3. **Добавьте query параметры** (опционально):
   - Нажмите "+" для добавления параметра
   - Введите название и значение
4. **Настройте тело запроса**:
   - Используйте шаблоны для быстрого заполнения
   - Или введите собственные данные

### Шаг 3: Отправка запроса
1. Нажмите кнопку **"Отправить запрос"**
2. Запрос будет отправлен через серверный прокси
3. Результат появится в разделе **"Отправленные запросы"** с полной информацией об ответе
4. Если URL - ваш тестовый вебхук, запрос также появится в **"Полученных запросах"**

## Примеры использования

### Тестирование внешнего API
```
URL: https://api.example.com/orders
Метод: POST
Заголовки:
  Content-Type: application/json
  User-Agent: DmIntegroff
  Authorization: Bearer your-token
Тело:
{
  "user_id": 123,
  "action": "create_order",
  "data": {
    "product_id": 456,
    "quantity": 2
  }
}
```

### Отладка с HTTPBin
```
URL: https://httpbin.org/post
Метод: POST
Заголовки:
  Content-Type: application/json
  User-Agent: DmIntegroff
Тело:
{
  "test": "data"
}
```

### XML запрос
```
Метод: POST
Заголовки:
  Content-Type: application/xml
Тело:
<?xml version="1.0" encoding="UTF-8"?>
<order>
    <user_id>123</user_id>
    <product_id>456</product_id>
    <quantity>2</quantity>
</order>
```

### Form Data запрос
```
Метод: POST
Заголовки:
  Content-Type: application/x-www-form-urlencoded
Тело:
user_id=123&product_id=456&quantity=2
```

### GET запрос с параметрами
```
Метод: GET
Query параметры:
  user_id: 123
  filter: active
  limit: 10
```

### Тестирование внешних API
```
URL: https://httpbin.org/post
Метод: POST
Результат: ✅ "Запрос выполнен: 200 OK (245ms)"
Ответ: Полный JSON с данными о запросе

URL: https://api.external-service.com/webhook  
Метод: POST
Результат: ✅ "Запрос выполнен: 201 Created (1200ms)" 
Ответ: Реальный ответ от API со всеми заголовками
```

## Преимущества

1. **Универсальность** - отправка на любой URL, не только на тестовый вебхук
2. **Полный контроль** - настройка всех аспектов HTTP запроса
3. **Быстрые шаблоны** - предустановленные форматы и тестовые сервисы
4. **Удобный интерфейс** - встроенный HTTP клиент без необходимости внешних инструментов
5. **Отладка интеграций** - тестирование реальных API прямо из интерфейса
6. **Без CORS ограничений** - запросы отправляются через сервер DmIntegroff, минуя браузерные ограничения
7. **Валидация** - проверка корректности URL и параметров
8. **Идентификация** - все запросы отправляются с User-Agent "DmIntegroff" для легкой идентификации в логах
9. **История запросов** - автоматическое сохранение всех отправленных запросов и ответов

## Совместимость

Функциональность работает со всеми существующими тестовыми вебхуками и не влияет на:
- Стандартную кнопку "Тестовый запрос"
- Автоматическое обновление списка запросов
- Функцию "Использовать как образец данных"
- Срок действия вебхуков (24 часа)

## Технические детали

### User-Agent

Все запросы, отправляемые через функцию кастомных запросов, автоматически включают заголовок:
```
User-Agent: DmIntegroff
```

Это позволяет:
- **Идентифицировать запросы** от DmIntegroff в логах внешних сервисов
- **Отслеживать трафик** от вашей системы интеграции
- **Отлаживать проблемы** с внешними API
- **Соблюдать этикет** веб-запросов (многие сервисы требуют User-Agent)

Заголовок User-Agent можно изменить или удалить в интерфейсе кастомного запроса, если это необходимо.

### Серверный прокси

Все кастомные запросы отправляются через встроенный HTTP прокси сервера DmIntegroff, что полностью решает проблему CORS:

**Преимущества:**
- ✅ **Нет CORS ограничений** - запросы идут с сервера, не из браузера
- ✅ **Полные ответы** - вы видите все заголовки и содержимое ответа
- ✅ **Реальные статус коды** - точная информация об успехе/ошибке
- ✅ **Время выполнения** - измерение скорости ответа сервера
- ✅ **Безопасность** - защита от запросов к локальным/приватным сетям

**Что вы получаете:**
- **Статус ответа**: HTTP код и текст (например, "200 OK", "404 Not Found")
- **Заголовки ответа**: все заголовки, возвращенные сервером
- **Тело ответа**: полное содержимое ответа (JSON, XML, HTML, текст)
- **Время выполнения**: сколько миллисекунд занял запрос
- **Детальные ошибки**: точная информация о проблемах сети или сервера

**Безопасность:**
- Запросы к внешним локальным адресам заблокированы (кроме собственного сервера)
- Запросы к приватным сетям (192.168.x.x, 10.x.x.x) заблокированы
- Разрешены запросы к собственному серверу dmIntegroff (тестовые вебхуки)
- Таймаут 30 секунд для предотвращения зависания
- Требуется авторизация пользователя

### Технические особенности

- Запросы отправляются через JavaScript Fetch API
- Поддерживаются все HTTP методы
- Query параметры автоматически кодируются
- Ошибки отображаются в виде уведомлений
- Модальное окно закрывается автоматически после успешной отправки
