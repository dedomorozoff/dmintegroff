# 🚀 Быстрый тест: Использование запроса как образца

## Запуск приложения

```bash
# Перейти в директорию проекта
cd dmintegroff

# Запустить приложение
./dmintegroff.exe
# или
go run cmd/server/main.go
```

## Быстрый тест (5 минут)

### 1. Войти в систему
```
http://localhost:8080/login
```

### 2. Создать тестовый webhook
1. На дашборде нажать "Создать тестовый вебхук"
2. Скопировать URL (например: `http://localhost:8080/webhook/test/abc123...`)

### 3. Отправить тестовый запрос

**Вариант A: Через curl**
```bash
curl -X POST "http://localhost:8080/webhook/test/YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "event": "test",
    "data": {
      "id": 123,
      "name": "Test User"
    }
  }'
```

**Вариант B: Через кнопку в UI**
Нажать "Отправить тестовый запрос" на странице webhook

### 4. Использовать как образец
1. Нажать на полученный запрос (раскрыть детали)
2. Нажать кнопку "Использовать как образец данных"
3. Выбрать интеграцию из списка
4. Проверить, что произошел редирект на страницу настройки
5. Убедиться, что образец данных заполнен

## Что проверить

✅ Кнопка "Использовать как образец данных" видна в деталях запроса  
✅ Модальное окно открывается при клике  
✅ Список интеграций загружается  
✅ При клике на интеграцию происходит сохранение  
✅ Показывается уведомление "Образец данных сохранён"  
✅ Происходит редирект на `/integrations/:id/configure`  
✅ Образец данных отображается в поле "Образец данных"

## Возможные проблемы

### Нет интеграций
**Решение:** Создать хотя бы одну интеграцию перед тестированием

### Модальное окно не открывается
**Решение:** Проверить консоль браузера на ошибки JavaScript

### Ошибка 404 при сохранении
**Решение:** Убедиться, что webhook и интеграция принадлежат текущему пользователю
