# 📝 Руководство по использованию JSON шаблонов

## Обзор

dmIntegroff поддерживает два способа трансформации данных:

1. **Простой маппинг полей** - переименование полей (например: `user.name` → `userName`)
2. **Кастомный JSON шаблон** - полный контроль над структурой выходного JSON

## Синтаксис шаблонов

### Базовый синтаксис

Используйте `{{field.path}}` для подстановки значений из источника данных.

```json
{
  "name": "{{user.name}}",
  "email": "{{user.email}}"
}
```

### Типы данных

#### Строки
Для строковых значений используйте кавычки:
```json
{
  "name": "{{user.name}}",
  "city": "{{address.city}}"
}
```

#### Числа и булевы значения
Для чисел и булевых значений кавычки **не нужны**:
```json
{
  "age": {{user.age}},
  "count": {{items.count}},
  "active": {{is_active}}
}
```

#### Вложенные объекты
```json
{
  "user": {
    "profile": {
      "name": "{{user.name}}",
      "age": {{user.age}}
    }
  }
}
```

#### Массивы

**Доступ к конкретному элементу:**
```json
{
  "first_item": "{{items[0].name}}",
  "second_item": "{{items[1].name}}"
}
```

**Копирование всего массива (wildcard):**
```json
{
  "all_items": {{items.*}}
}
```

> 💡 **Новое!** Используйте `{{array.*}}` для копирования массивов неизвестной длины.  
> Подробнее: [ARRAY_WILDCARD.md](ARRAY_WILDCARD.md)

### Статические значения

Можно комбинировать динамические и статические значения:

```json
{
  "user_name": "{{user.name}}",
  "api_version": "v1",
  "source": "dmIntegroff",
  "timestamp": "{{timestamp}}"
}
```

## Примеры использования

### Пример 1: Простая трансформация

**Входные данные:**
```json
{
  "firstName": "Иван",
  "lastName": "Петров",
  "email": "ivan@example.com"
}
```

**Шаблон:**
```json
{
  "user": {
    "name": "{{firstName}}",
    "surname": "{{lastName}}",
    "contact": "{{email}}"
  }
}
```

**Результат:**
```json
{
  "user": {
    "name": "Иван",
    "surname": "Петров",
    "contact": "ivan@example.com"
  }
}
```

### Пример 2: Работа с вложенными объектами

**Входные данные:**
```json
{
  "user": {
    "profile": {
      "name": "Мария",
      "age": 25
    },
    "settings": {
      "notifications": true
    }
  }
}
```

**Шаблон:**
```json
{
  "userName": "{{user.profile.name}}",
  "userAge": {{user.profile.age}},
  "notificationsEnabled": {{user.settings.notifications}}
}
```

**Результат:**
```json
{
  "userName": "Мария",
  "userAge": 25,
  "notificationsEnabled": true
}
```

### Пример 3: Работа с массивами

**Входные данные:**
```json
{
  "order": {
    "id": "12345",
    "items": [
      {"name": "Товар 1", "price": 100},
      {"name": "Товар 2", "price": 200}
    ]
  }
}
```

**Шаблон:**
```json
{
  "orderId": "{{order.id}}",
  "firstItem": {
    "name": "{{order.items[0].name}}",
    "price": {{order.items[0].price}}
  },
  "secondItem": {
    "name": "{{order.items[1].name}}",
    "price": {{order.items[1].price}}
  }
}
```

**Результат:**
```json
{
  "orderId": "12345",
  "firstItem": {
    "name": "Товар 1",
    "price": 100
  },
  "secondItem": {
    "name": "Товар 2",
    "price": 200
  }
}
```

### Пример 4: Комбинирование со статическими значениями

**Входные данные:**
```json
{
  "event": "user_registered",
  "user": {
    "id": 123,
    "email": "user@example.com"
  }
}
```

**Шаблон:**
```json
{
  "event_type": "{{event}}",
  "user_id": {{user.id}},
  "user_email": "{{user.email}}",
  "source": "webhook",
  "version": "1.0",
  "processed_by": "dmIntegroff"
}
```

**Результат:**
```json
{
  "event_type": "user_registered",
  "user_id": 123,
  "user_email": "user@example.com",
  "source": "webhook",
  "version": "1.0",
  "processed_by": "dmIntegroff"
}
```

### Пример 5: Реструктуризация данных

**Входные данные (от CRM):**
```json
{
  "lead": {
    "contact": {
      "first_name": "Алексей",
      "last_name": "Смирнов",
      "phone": "+7 999 123-45-67",
      "email": "alex@example.com"
    },
    "source": "website",
    "created_at": "2024-11-30T10:00:00Z"
  }
}
```

**Шаблон (для отправки в другую систему):**
```json
{
  "customer": {
    "fullName": "{{lead.contact.first_name}} {{lead.contact.last_name}}",
    "contacts": {
      "phone": "{{lead.contact.phone}}",
      "email": "{{lead.contact.email}}"
    }
  },
  "metadata": {
    "source": "{{lead.source}}",
    "timestamp": "{{lead.created_at}}",
    "integration": "dmIntegroff"
  }
}
```

**Результат:**
```json
{
  "customer": {
    "fullName": "Алексей Смирнов",
    "contacts": {
      "phone": "+7 999 123-45-67",
      "email": "alex@example.com"
    }
  },
  "metadata": {
    "source": "website",
    "timestamp": "2024-11-30T10:00:00Z",
    "integration": "dmIntegroff"
  }
}
```

## Валидация шаблона

Перед сохранением используйте кнопку **"Проверить шаблон"** для валидации:

✅ **Валидный шаблон:**
```json
{
  "name": "{{user.name}}",
  "age": {{user.age}}
}
```

❌ **Невалидный шаблон (пропущена запятая):**
```json
{
  "name": "{{user.name}}"
  "age": {{user.age}}
}
```

❌ **Невалидный шаблон (лишняя запятая):**
```json
{
  "name": "{{user.name}}",
  "age": {{user.age}},
}
```

## Советы и рекомендации

### 1. Используйте правильные кавычки
- ✅ Строки: `"{{field}}"`
- ✅ Числа: `{{field}}`
- ✅ Булевы: `{{field}}`

### 2. Проверяйте структуру JSON
Используйте онлайн-валидаторы JSON или встроенную проверку в dmIntegroff.

### 3. Тестируйте на реальных данных
Отправьте тестовый webhook и проверьте результат в логах.

### 4. Документируйте сложные шаблоны
Для сложных трансформаций добавляйте комментарии в описание интеграции.

### 5. Используйте доступные поля
В интерфейсе настройки есть раздел **"Доступные поля для подстановки"** со списком всех полей из образца данных.

## Отладка

### Проверка результата
1. Настройте шаблон
2. Отправьте тестовый webhook
3. Проверьте логи в разделе **"Логи"**
4. Посмотрите, что было отправлено на Target API

### Частые ошибки

**Ошибка:** `Failed to process output template`
- **Причина:** Невалидный JSON или неправильный синтаксис
- **Решение:** Проверьте шаблон через кнопку "Проверить шаблон"

**Ошибка:** Поле подставляется как `null`
- **Причина:** Поле не найдено в источнике данных
- **Решение:** Проверьте путь к полю в разделе "Доступные поля"

## Сравнение с простым маппингом

| Функция | Простой маппинг | Кастомный шаблон |
|---------|----------------|------------------|
| Переименование полей | ✅ | ✅ |
| Изменение структуры | ❌ | ✅ |
| Статические значения | ❌ | ✅ |
| Вложенные объекты | ✅ | ✅ |
| Массивы | ✅ | ✅ |
| Сложность настройки | Простая | Средняя |

## Когда использовать каждый метод

### Простой маппинг
- Нужно только переименовать поля
- Структура данных остается той же
- Быстрая настройка

### Кастомный шаблон
- Нужно изменить структуру данных
- Требуются статические значения
- Сложная трансформация
- Полный контроль над выходом

---

💡 **Совет:** Начните с простого маппинга, а если его недостаточно - переключитесь на кастомный шаблон.
