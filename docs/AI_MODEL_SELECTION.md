# 🤖 Выбор AI модели в dmIntegroff

Руководство по настройке и выбору AI модели для ассистента.

---

## 🎯 Обзор

dmIntegroff поддерживает различные AI модели через OpenRouter и OpenAI API. Администраторы могут выбирать оптимальную модель для своих задач прямо в интерфейсе настроек.

---

## 🚀 Быстрый старт

### 1. Включение AI (если отключено)

Проверьте файл `.env` и убедитесь что AI включен:
```bash
AI_ENABLED=true
```

Если `AI_ENABLED=false`, то AI функциональность полностью отключена независимо от других настроек.

### 2. Получение API ключа

**OpenRouter (рекомендуется):**
1. Перейдите на https://openrouter.ai/keys
2. Зарегистрируйтесь или войдите в аккаунт
3. Создайте новый API ключ
4. Скопируйте ключ (начинается с `sk-or-v1-`)

**OpenAI (fallback):**
1. Перейдите на https://platform.openai.com/api-keys
2. Войдите в аккаунт OpenAI
3. Создайте новый API ключ
4. Скопируйте ключ (начинается с `sk-`)

### 3. Настройка в интерфейсе

1. Войдите как администратор
2. Перейдите в **Настройки** (`/settings`)
3. Найдите секцию **"Настройки AI Ассистента"**
4. Вставьте API ключ OpenRouter
5. Выберите модель из списка
6. Нажмите **"Сохранить настройки"**
7. Перезапустите сервер

## 🧠 Рекомендуемые модели

### Для программирования и анализа
- **Claude 3.5 Sonnet** - лучший выбор для создания маппингов и анализа JSON
- **GPT-4o** - отличная альтернатива, быстрый и качественный

### Для простых задач
- **Claude 3 Haiku** - самый быстрый, подходит для простых вопросов
- **GPT-4o Mini** - экономичный вариант от OpenAI

### Для больших контекстов
- **Gemini Pro 1.5** - поддерживает очень большие контексты
- **Claude 3.5 Sonnet** - также хорошо работает с большими данными

### Открытые модели
- **Llama 3.1 70B** - качественная открытая модель
- **Llama 3.1 8B** - более быстрая версия

## ⚙️ Параметры настройки

### Максимальное количество токенов (100-8000)
- **1000-2000** - для простых задач и быстрых ответов
- **4000** - оптимальное значение для большинства задач
- **6000-8000** - для сложных маппингов и анализа

### Температура (0-2)
- **0.1-0.3** - для точных технических задач (рекомендуется)
- **0.5-0.7** - для более креативных ответов
- **0.8-1.0** - для максимальной креативности

### Таймаут запроса (5-120 секунд)
- **10-20 секунд** - для быстрых моделей
- **30 секунд** - оптимальное значение (по умолчанию)
- **60-120 секунд** - для сложных задач

## 🔧 API Endpoints

### Получение списка моделей
```bash
GET /api/ai/models
```

**Ответ:**
```json
{
  "recommended": [
    {
      "id": "anthropic/claude-3.5-sonnet",
      "name": "Claude 3.5 Sonnet",
      "description": "Лучший для сложных задач программирования"
    }
  ],
  "openrouter": [...],
  "openrouter_available": true
}
```

### Сохранение настроек AI
```bash
POST /api/settings/ai
Content-Type: application/json

{
  "openrouter_api_key": "sk-or-v1-...",
  "openrouter_model": "anthropic/claude-3.5-sonnet",
  "max_tokens": 4000,
  "temperature": 0.3,
  "request_timeout": 30
}
```

### Проверка статуса AI
```bash
GET /api/ai/status
```

## 🐛 Устранение неполадок

### AI отключен
**Симптомы:** Серый индикатор статуса, сообщение "AI отключен"

**Причина:** `AI_ENABLED=false` в .env файле

**Решение:** 
1. Откройте файл `.env`
2. Измените `AI_ENABLED=false` на `AI_ENABLED=true`
3. Перезапустите сервер

### AI недоступен
**Симптомы:** Красный индикатор статуса, ошибка "AI не настроен"

**Решения:**
1. Убедитесь что `AI_ENABLED=true` в .env
2. Проверьте правильность API ключа
3. Убедитесь что есть интернет соединение
4. Проверьте баланс на OpenRouter/OpenAI аккаунте
5. Попробуйте другую модель

### Медленные ответы
**Причины:**
- Большое количество токенов (>6000)
- Медленная модель
- Высокая нагрузка на API

**Решения:**
- Уменьшите max_tokens до 2000-4000
- Выберите более быструю модель (Haiku, GPT-4o Mini)
- Увеличьте таймаут до 60 секунд

### Некачественные ответы
**Причины:**
- Слишком высокая температура
- Неподходящая модель для задачи
- Недостаточно контекста

**Решения:**
- Установите температуру 0.1-0.3
- Используйте Claude 3.5 Sonnet для технических задач
- Предоставьте больше контекста в запросе

## 🔄 Миграция с статических настроек

Если у вас уже настроены AI ключи в `.env` файле:

1. Скопируйте значения из `.env`:
   ```bash
   OPENROUTER_API_KEY=your-key
   OPENROUTER_MODEL=anthropic/claude-3.5-sonnet
   ```

2. Вставьте их в интерфейс настроек

3. Сохраните настройки

4. Перезапустите сервер

5. (Опционально) Удалите старые настройки из `.env`
