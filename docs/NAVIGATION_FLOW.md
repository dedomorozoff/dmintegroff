# Схема навигации между страницами интеграции

## Визуальная схема

```
┌─────────────────────────────────────────────────────────────────┐
│                     Список интеграций                            │
│                    /integrations                                 │
└────────────┬────────────────────────────────────┬────────────────┘
             │                                    │
             │ Создать                            │ Редактировать
             ▼                                    ▼
┌─────────────────────────┐          ┌─────────────────────────────┐
│  Создание интеграции    │          │  Редактирование интеграции  │
│  /integrations/create   │          │  /integrations/{id}/edit    │
│                         │          │                             │
│  • Название             │          │  • Название                 │
│  • Target API           │          │  • Target API               │
│  • HTTP метод           │          │  • HTTP метод               │
│  • Аутентификация       │          │  • Аутентификация           │
│  • Заголовки            │          │  • Заголовки                │
│  • Webhook подписи      │          │  • Webhook подписи          │
└────────────┬────────────┘          └──────────┬──────────────────┘
             │                                  │
             │ Создать                          │ Настроить маппинг ⭐
             ▼                                  ▼
┌─────────────────────────────────────────────────────────────────┐
│              Настройка маппинга полей                            │
│              /integrations/{id}/configure                        │
│                                                                  │
│  • Просмотр образца данных                                      │
│  • Выбор режима трансформации:                                  │
│    - Простой маппинг полей                                      │
│    - Кастомный шаблон (JSON/XML/Text/Custom)                   │
│  • Настройка трансформации                                      │
│  • Активация интеграции                                         │
│                                                                  │
│  [Настройки интеграции ⭐] ← Быстрый переход                    │
└─────────────────────────────────────────────────────────────────┘
```

⭐ - Новые кнопки быстрого перехода

## Детальный flow

### 1. Создание новой интеграции

```
Список интеграций
    ↓ [Создать интеграцию]
Создание интеграции
    ↓ [Создать]
Настройка маппинга (режим listening)
    ↓ Отправить webhook
Настройка маппинга (с данными)
    ↓ [Сохранить и активировать]
Список интеграций (интеграция активна)
```

### 2. Редактирование существующей интеграции

```
Список интеграций
    ↓ [Редактировать]
Редактирование интеграции
    ↓ [Настроить маппинг] ⭐ НОВОЕ
Настройка маппинга
    ↓ [Настройки интеграции] ⭐ НОВОЕ
Редактирование интеграции
    ↓ [Сохранить изменения]
Список интеграций
```

### 3. Быстрая настройка маппинга

```
Список интеграций
    ↓ [Редактировать]
Редактирование интеграции
    ↓ [Настроить маппинг] ⭐ (в заголовке)
Настройка маппинга
    ↓ [Сохранить изменения]
Список интеграций
```

### 4. Отладка интеграции

```
Список интеграций
    ↓ [Редактировать]
Редактирование интеграции
    ↓ [Настроить маппинг] ⭐
Настройка маппинга
    ↓ Проверка трансформации
    ↓ [Настройки интеграции] ⭐
Редактирование интеграции
    ↓ Проверка заголовков/auth
    ↓ [Настроить маппинг] ⭐
Настройка маппинга
    ↓ [Сохранить изменения]
Список интеграций
```

```
│ Изменение параметров интеграции                             │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  [Форма редактирования]                                     │
│                                                              │
├─────────────────────────────────────────────────────────────┤
│ [Сохранить] [Настроить маппинг] ⭐ [Отмена]                 │
└─────────────────────────────────────────────────────────────┘
```

### Страница настройки маппинга

```
┌─────────────────────────────────────────────────────────────┐
│ Настройка маппинга полей      [Настройки интеграции] ⭐     │
│ Интеграция: Название                                        │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  [Форма настройки маппинга]                                 │
│                                                              │
├─────────────────────────────────────────────────────────────┤
│ [Сохранить] [Настройки интеграции] ⭐ [Отмена]              │
└─────────────────────────────────────────────────────────────┘
```

## Условия отображения кнопок

### Кнопка "Настроить маппинг"

**Показывается:**
- ✅ Интеграция в режиме `active`
- ✅ Интеграция в режиме `inactive`

**НЕ показывается:**
- ❌ Интеграция в режиме `listening` (нет данных для маппинга)

**Логика:**
```go
{{ if ne .integration.Mode "listening" }}
    <a href="/integrations/{{ .integration.ID }}/configure">
        Настроить маппинг
    </a>
{{ end }}
```

### Кнопка "Настройки интеграции"

**Показывается:**
- ✅ Всегда (на странице маппинга)

**Логика:**
```html
<a href="/integrations/{{ .integration.ID }}/edit">
    Настройки интеграции
</a>
```

## Дополнительные кнопки

### GraphQL интеграции

```
[Сохранить] [Настроить GraphQL] [Настроить маппинг] ⭐ [Отмена]
```

### REST с обогащением

```
[Сохранить] [Обогащение данных] [Настроить маппинг] ⭐ [Отмена]
```

## Мобильная версия

На мобильных устройствах кнопки переносятся на новую строку благодаря `flex-wrap: wrap`:

```
┌─────────────────────────┐
│ [Сохранить изменения]   │
│ [Настроить маппинг] ⭐  │
│ [Отмена]                │
└─────────────────────────┘
```

## Иконки

- **Настроить маппинг:** `shuffle` (🔀)
- **Настройки интеграции:** `settings` (⚙️)
- **Сохранить:** `save` (💾)
- **Активировать:** `check-circle` (✅)

## Цветовая схема

- **Primary (синий):** Основные действия (переходы между страницами)
- **Success (зеленый):** Сохранение данных
- **Secondary (серый):** Вспомогательные действия (отмена, кнопки в заголовке)

## Keyboard shortcuts (будущее)

Возможные горячие клавиши:
- `Ctrl+M` - Перейти к маппингу
- `Ctrl+E` - Перейти к редактированию
- `Ctrl+S` - Сохранить
- `Esc` - Отмена

## Аналитика использования

Рекомендуется отслеживать:
- Частота использования кнопок быстрого перехода
- Среднее время между переходами
- Наиболее популярные пути навигации
- Точки выхода из flow

## Обратная связь пользователей

Собирать feedback по:
- Удобству расположения кнопок
- Необходимости дополнительных переходов
- Предложениям по улучшению навигации
