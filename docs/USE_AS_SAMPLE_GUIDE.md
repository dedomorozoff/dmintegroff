# 📥 Использование запроса как образца данных

## Описание

Функция "Использовать как образец данных" позволяет быстро настроить маппинг интеграции на основе реальных данных, полученных через тестовый webhook.

## Зачем это нужно?

При настройке интеграции вам нужен образец данных (JSON), чтобы:
- Увидеть структуру входящих данных
- Настроить маппинг полей
- Протестировать трансформацию

Раньше приходилось:
1. Получить webhook на реальную интеграцию
2. Скопировать JSON вручную
3. Вставить в поле образца данных

Теперь можно:
1. Отправить тестовый запрос
2. Одним кликом использовать его как образец
3. Сразу перейти к настройке маппинга

## Как использовать

### Шаг 1: Создайте тестовый webhook

1. На дашборде нажмите кнопку **"Создать тестовый вебхук"**
2. Скопируйте URL тестового webhook

![Создание тестового webhook](./images/create-test-webhook.png)

### Шаг 2: Отправьте тестовый запрос

Отправьте POST запрос с вашими данными:

```bash
curl -X POST "http://localhost:8080/webhook/test/YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "event": "order.created",
    "order": {
      "id": "ORD-12345",
      "customer": {
        "name": "Иван Иванов",
        "email": "ivan@example.com"
      },
      "total": 1500.00,
      "items": [
        {
          "product": "Товар 1",
          "quantity": 2,
          "price": 750.00
        }
      ]
    }
  }'
```

Или используйте кнопку **"Отправить тестовый запрос"** на странице webhook.

### Шаг 3: Используйте запрос как образец

1. На странице тестового webhook найдите полученный запрос
2. Нажмите на запрос, чтобы раскрыть детали
3. Нажмите кнопку **"Использовать как образец данных"**

![Кнопка использования как образец](./images/use-as-sample-button.png)

### Шаг 4: Выберите интеграцию

1. В открывшемся модальном окне выберите интеграцию
2. Нажмите на нужную интеграцию

![Выбор интеграции](./images/select-integration-modal.png)

### Шаг 5: Настройте маппинг

После выбора интеграции вы автоматически перейдете на страницу настройки маппинга, где:
- Образец данных уже заполнен
- Можно сразу начать настройку маппинга
- Доступны все поля из образца для использования в шаблоне

![Настройка маппинга](./images/configure-mapping.png)

## Преимущества

✅ **Быстро** - один клик вместо копирования и вставки  
✅ **Удобно** - автоматический переход к настройке  
✅ **Безопасно** - работает только с вашими интеграциями  
✅ **Гибко** - можно использовать один запрос для нескольких интеграций  

## Частые вопросы

### Можно ли использовать один запрос для нескольких интеграций?

Да! Вы можете использовать один и тот же тестовый запрос для настройки нескольких интеграций.

### Что будет, если у интеграции уже есть образец данных?

Образец данных будет перезаписан новым. Если вам нужно сохранить старый образец, скопируйте его перед использованием новой функции.

### Можно ли использовать запросы без body?

Да, но в этом случае образец данных будет пустым. Это может быть полезно для GET запросов или запросов с данными в query параметрах.

### Как долго хранятся тестовые запросы?

Тестовые webhook и их запросы хранятся 24 часа с момента создания. После этого они автоматически удаляются.

### Можно ли редактировать образец после сохранения?

Да! На странице настройки маппинга есть кнопка "Редактировать JSON", которая позволяет изменить образец данных вручную.

## Техническая информация

### API Endpoint

```
POST /api/webhook-test/:token/use-as-sample/:request_id
```

**Request Body:**
```json
{
  "integration_id": 1
}
```

**Response:**
```json
{
  "status": "success",
  "message": "Request saved as sample payload",
  "integration_id": 1,
  "redirect_url": "/integrations/1/configure"
}
```

### Безопасность

- Функция доступна только авторизованным пользователям
- Можно использовать только свои тестовые webhook
- Можно сохранять образцы только в свои интеграции
- Все действия логируются
