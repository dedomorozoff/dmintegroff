# Настройка работы только с бесплатными AI моделями

## Обзор

Приложение dmIntegroff настроено для работы исключительно с бесплатными AI моделями через OpenRouter API. Это исключает любые расходы на кредиты и решает проблемы с недостатком средств.

## Изменения в коде

### 1. Контроллер AI (`internal/controllers/ai_controller.go`)

- **GetModels()**: Модифицирован для возврата только бесплатных моделей
- Обновлен список популярных моделей - только бесплатные варианты
- Все категории (`openrouter_all`, `openrouter_popular`) теперь содержат только бесплатные модели

### 2. AI клиент (`internal/ai/client.go`)

- **GetRecommendedModels()**: Обновлен список рекомендуемых моделей
- Заменены платные модели (Claude, GPT-4) на бесплатные (Llama, Gemma, Phi-3)

### 3. Интерфейс (`templates/pages/settings.html`)

- Обновлены все подсказки и описания
- Добавлены эмодзи 🆓 для выделения бесплатности
- Изменены рекомендации с Claude на Llama 3.1 8B
- Обновлено модальное окно поиска моделей

## Доступные бесплатные модели

### Рекомендуемые модели:
1. **Llama 3.2 3B (Бесплатно)** - Быстрая модель для простых задач
2. **Llama 3.1 8B (Бесплатно)** - Хорошая модель для программирования
3. **Gemma 2 9B (Бесплатно)** - Модель Google для общих задач
4. **Phi-3 Mini (Бесплатно)** - Компактная модель Microsoft
5. **Qwen 2 7B (Бесплатно)** - Многоязычная модель

### Популярные бесплатные модели:
- `meta-llama/llama-3.2-3b-instruct:free`
- `meta-llama/llama-3.1-8b-instruct:free`
- `google/gemma-2-9b-it:free`
- `microsoft/phi-3-mini-128k-instruct:free`
- `qwen/qwen-2-7b-instruct:free`
- `mistralai/mistral-7b-instruct:free`
- `huggingfaceh4/zephyr-7b-beta:free`

## Преимущества

1. **Никаких расходов** - все модели полностью бесплатные
2. **Нет проблем с кредитами** - исключены ошибки "insufficient credits"
3. **Простота использования** - не нужно следить за балансом
4. **Хорошее качество** - современные открытые модели показывают отличные результаты

## Рекомендации по использованию

- **Для программирования**: Llama 3.1 8B
- **Для простых задач**: Llama 3.2 3B или Phi-3 Mini
- **Для многоязычных задач**: Qwen 2 7B
- **Для общих задач**: Gemma 2 9B

## Настройки токенов

Для бесплатных моделей рекомендуется:
- **max_tokens**: 1000-2000 (оптимально для большинства задач)
- **temperature**: 0.3-0.7 (баланс между точностью и креативностью)
- **timeout**: 30 секунд (достаточно для большинства запросов)

## Получение API ключа

1. Перейдите на https://openrouter.ai/keys
2. Создайте бесплатный аккаунт
3. Сгенерируйте API ключ
4. Добавьте ключ в настройки приложения

**Важно**: Даже с бесплатным аккаунтом OpenRouter вы получаете доступ ко всем бесплатным моделям без ограничений по кредитам.
