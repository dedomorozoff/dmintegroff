# 🚀 AI Демо Режим - Быстрый старт

Демо режим AI позволяет изучить возможности искусственного интеллекта в dmIntegroff за 5 минут без настройки API ключей.

## ⚡ Быстрая активация

### 1. Включите демо режим
Добавьте в `.env` файл:
```env
DEMO_MODE=true
```

### 2. Перезапустите сервер
```bash
go run cmd/server/main.go
```

### 3. Проверьте статус
Откройте http://localhost:8080/api/ai/status

Должен вернуться:
```json
{
  "demo_mode": true,
  "available": true,
  "provider": "Demo Mode",
  "demo_message": "AI функции работают в демонстрационном режиме"
}
```

## 🎯 Что попробовать

### 1. AI Чат-Ассистент
**URL:** `/ai/chat` (в интерфейсе)

**Попробуйте спросить:**
- "Как настроить уведомления в Slack?"
- "Создать интеграцию с Telegram"
- "Помощь с Discord webhook"
- "Интеграция с AmoCRM"
- "Отправка email уведомлений"

**Результат:** Получите детальные инструкции и предложения

### 2. Анализ Данных
**URL:** `/api/ai/analyze-data`

**Тестовые данные:**
```json
{
  "data": {
    "order_id": "12345",
    "customer_email": "user@example.com",
    "customer_phone": "+7 999 123-45-67",
    "total_amount": 99.99,
    "order_date": "2024-12-27T10:30:00Z",
    "items": ["Product A", "Product B"]
  },
  "format": "json"
}
```

**Результат:** AI определит типы полей и предложит маппинги

### 3. Генерация Маппингов
**URL:** `/api/ai/generate-mapping`

**Пример запроса:**
```json
{
  "source_data": {
    "message": "Новый заказ",
    "user": "Иван Петров",
    "amount": 1500
  },
  "target_api": "slack",
  "task": "Отправить уведомление о заказе",
  "user_prompt": "Хочу красивое сообщение с эмодзи"
}
```

**Результат:** Готовый шаблон для Slack с форматированием

### 4. Создание Интеграции
**URL:** `/api/ai/create-integration`

**Пример запроса:**
```json
{
  "description": "Отправлять уведомления о новых заказах в Telegram",
  "sample_data": "{\"order_id\": 123, \"customer\": \"Иван\", \"total\": 1500}",
  "project_id": 1
}
```

**Результат:** Полная интеграция с шаблоном и инструкциями

## 🔍 Что показывает демо

### ✅ Работает в демо режиме:
- **Анализ данных** - определение типов полей
- **Генерация шаблонов** - для популярных API
- **Создание интеграций** - полный цикл
- **Предложения** - следующие шаги
- **Документация** - инструкции и примеры

### ⚠️ Ограничения демо режима:
- **Предопределенные ответы** - не адаптируются под данные
- **Демо URL** - содержат DEMO префиксы
- **Нет персонализации** - одинаковые ответы для похожих запросов
- **Базовые шаблоны** - без сложной логики

## 🚀 Переход на реальный AI

Когда будете готовы к реальному AI:

### 1. Получите API ключ
- **OpenRouter** (рекомендуется): https://openrouter.ai/keys
- **OpenAI** (альтернатива): https://platform.openai.com/api-keys

### 2. Обновите конфигурацию
```env
# Отключите демо режим
DEMO_MODE=false

# Включите AI
AI_ENABLED=true

# Добавьте API ключ
OPENROUTER_API_KEY=sk-or-v1-your-key-here
```

### 3. Выберите модель
```env
# Для качества
OPENROUTER_MODEL=anthropic/claude-3.5-sonnet

# Для экономии
OPENROUTER_MODEL=openai/gpt-4o-mini

# Бесплатная
OPENROUTER_MODEL=meta-llama/llama-3.1-8b-instruct:free
```
